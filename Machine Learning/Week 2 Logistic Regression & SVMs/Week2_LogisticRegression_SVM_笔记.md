## 0. 这一讲在讲什么？

Week 1 Linear Regression 讲了**回归**的完整流程。这一讲回到**分类**（Intro 里影评好/坏的问题），把流程补全：

| 环节 | 逻辑回归 Logistic Regression | 支持向量机 SVM |
|---|---|---|
| 模型 | sign(θᵀx) | sign(θᵀx) ← **完全一样** |
| 代价函数 | **logistic loss** log(1 + e^(−yθᵀx)) | **hinge loss** max(0, 1 − yθᵀx) + 惩罚项 θᵀθ/C |
| 优化 | 梯度下降 | 次梯度下降（subgradient descent） |

> 💡 本讲最重要的一个认识（课件 Slide 18 原话的意思）：**逻辑回归和 SVM 唯一的区别就是 cost function 的选择。** 模型是一样的，都是一条（一个）线性决策边界。
>
> 💡 另一个贯穿全讲的关键量：**y·θᵀx**（叫 **margin**）。> 0 说明分类正确，而且越大越"有把握"。理解了它，两种 loss 函数就都懂了。

### 1.1 例子

## 2. 模型与决策边界（Slide 3–5）

### 2.1 模型
和之前一样：θᵀx = θ₀x₀ + θ₁x₁ + … + θₙxₙ，x₀ = 1。

**模型：sign(θᵀx)**
- θᵀx > 0 → 预测 +1
- θᵀx < 0 → 预测 −1

### 2.2 决策边界 Decision Boundary
**θᵀx = 0** 这个集合就是**决策边界**：一边预测 +1，另一边预测 −1。

| 特征个数 | 决策边界是 | 课件例子 |
|---|---|---|
| 1 个 | 一个**点** | 1 + 0.5x₁ = 0 → x₁ = −2 |
| 2 个 | 一条**直线** | 2 + x₁ + 2x₂ = 0 → x₂ = −x₁/2 − 1 |
| 3 个或更多 | 一个**平面 / 超平面** | |

> 💡 怎么从方程画直线：2 + x₁ + 2x₂ = 0，把 x₂ 解出来就是 x₂ = −x₁/2 − 1，斜率 −1/2，截距 −1。在直线的哪一侧预测 +1？随便代一个点试试：原点 (0,0) → 2 + 0 + 0 = 2 > 0 → 原点那一侧是 +1。

### 2.3 例子（Slide 4）
x = [1, x₁, x₂]ᵀ，比如 x₁ = 肿瘤大小，x₂ = 病人年龄。参数 θ₀ = 0, θ₁ = 0.5, θ₂ = −0.5：
- sign(θᵀx) = +1 ⟺ 0.5x₁ − 0.5x₂ > 0 ⟺ **x₁ > x₂**
- 决策边界是对角线 x₁ = x₂
- 左边的 3D 图：竖轴是 θᵀx 的值，它是一个倾斜的平面，这个平面和高度 0 的交线就是决策边界
- 右边是更常用的 2D 画法：只画 (x₁, x₂) 平面上的数据点和那条边界线（更容易画）

**线性可分（linearly separable）**：如果数据能被这样一条直线（超平面）完全正确地分开，就说数据是线性可分的。

### 2.4 不是所有数据都线性可分（Slide 5）
比如一类数据被另一类包围。这时要么接受一些错误，要么用 Week 2 Feature Engineering 的方法（比如加 x₁²、x₂² 特征）换到一个线性可分的特征空间。

## 3. 怎么选参数 θ？—— cost function 的选择（Slide 6–8）

训练数据：{(x⁽¹⁾, y⁽¹⁾), …, (x⁽ᵐ⁾, y⁽ᵐ⁾)}，x₀ = 1，y ∈ {−1, 1}。模型 h_θ(x) = sign(θᵀx)。问题：θ 选什么？也就是**用什么 cost function？**

### 3.1 尝试一：平方误差（Slide 7）—— 有问题
用线性回归的方法：最小化 (1/m) Σ (θᵀx⁽ⁱ⁾ − y⁽ⁱ⁾)²，也就是把 ±1 标签当作数值做线性回归，然后取 sign。

- 大致相当于"用眼睛画一条拟合线"
- **左图情况还行**：绿线左边 sign = −1，右边 sign = +1
- **右图出问题**：如果在右边很远的地方有一些 +1 的点，它们会**把 θᵀx 过零的位置往右拽**，导致中间一些点被分错

> 💡 **为什么会这样？** 平方误差要求 θᵀx **尽量等于** y = +1。一个远在右边的 +1 点，θᵀx 可能等于 5，明明分类完全正确，但平方误差 (5 − 1)² = 16 很大！于是平方误差会"惩罚"这个**正确且很有把握**的点，为了减小它的误差，把整条线压平/右移，结果牺牲了边界附近的点。
> **分类问题中，"太正确"不应该被惩罚。** 这就是需要专门为分类设计 loss 的原因。

### 3.2 尝试二：0-1 loss（Slide 8）—— 理想但难用
$$\frac{1}{m}\sum_{i=1}^{m} I\left(h_\theta(x^{(i)}) \neq y^{(i)}\right)$$

I 是**指示函数（indicator function）**：预测错了为 1，对了为 0。所以这就是**错误率**——最直接的目标。

**但很难用（hard to work with）**：
- 它是**阶梯状**的：θ 稍微变一点，错误数通常不变，所以**导数几乎处处为 0**，梯度下降完全不知道往哪走
- 在跳变的地方又**不可导**
- 数学上，直接最小化 0-1 loss 是一个非常难（NP-hard）的组合优化问题

### 3.3 逻辑回归的选择：logistic loss（Slide 8）
$$\frac{1}{m}\sum_{i=1}^{m} \frac{\log\left(1 + e^{-y^{(i)}\theta^T x^{(i)}}\right)}{\log 2}$$

- 除以 log(2) 是**可选的**，只是为了让 y·θᵀx = 0 时 loss 正好等于 1（log(1 + e⁰)/log 2 = log 2/log 2 = 1），方便和 0-1 loss 比较。不影响最优的 θ。

## 4. 理解 logistic loss（Slide 9）—— 重点

### 4.1 关键变量：margin z = y·θᵀx
| 情况 | y | θᵀx | z = y·θᵀx | 含义 |
|---|---|---|---|---|
| 正确且有把握 | +1 | 大正数 | 大正数 | 👍 |
| 正确且有把握 | −1 | 大负数 | 大正数 | 👍 |
| 在边界上 | ±1 | 0 | 0 | 模棱两可 |
| 错误 | +1 | 负数 | 负数 | 👎 |
| 错得离谱 | −1 | 大正数 | 大负数 | 👎👎 |

所以 **z > 0 ⟺ 分类正确**，z 越大越有把握；z 越负错得越离谱。用 ±1 标签的好处就在这：一个 z 同时处理了两个类别。

### 4.2 loss 作为 z 的函数：log(1 + e^(−z))/log 2
| z = y·θᵀx | −3 | −2 | 0 | 2 | 3 |
|---|---|---|---|---|---|
| logistic loss | 4.40 | 3.07 | 1 | 0.18 | 0.07 |

- z 很大（正确且有把握）→ loss 接近 **0**，但永远不完全等于 0
- z = 0（在边界上）→ loss = 1
- z 很负（分错）→ loss **大约随 |z| 线性增长**

Slide 9 两张图：
- 左图 y = +1：loss 关于 θᵀx 从左上往右下降 → θᵀx 越大越好
- 右图 y = −1：镜像，θᵀx 越小（越负）越好

**结论**：
- θᵀx ≫ 0 且 y = 1，或 θᵀx ≪ 0 且 y = −1 时，惩罚很小
- 最小化这个 loss 会偏好那些**把 θᵀx 推得远离决策边界 θᵀx = 0** 的 θ——即不仅要分对，还要分得有把握

> 💡 对比 3.1：平方误差会惩罚"太正确"的点，logistic loss **不会**（z 越大 loss 越小）。对比 3.2：logistic loss 是**光滑、可导、凸**的，可以用梯度下降。它是 0-1 loss 的一个"好用的替代品"（surrogate）。

### 4.3 【拓展】为什么叫"逻辑"回归？loss 从哪来？（课件没讲）
定义 **sigmoid / logistic 函数**：

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

它把任意实数压缩到 (0, 1)，形状是 S 形曲线：σ(0) = 0.5，σ(大正数) → 1，σ(大负数) → 0。

逻辑回归的概率解释：

$$P(y = +1 \mid x) = \sigma(\theta^T x), \quad P(y = -1 \mid x) = 1 - \sigma(\theta^T x) = \sigma(-\theta^T x)$$

两种情况可以合写为 **P(y | x) = σ(y·θᵀx)**（又一次用上 ±1 标签的好处）。

那么一个样本的 −log(概率)：

$$-\log P(y \mid x) = -\log \frac{1}{1 + e^{-y\theta^T x}} = \log\left(1 + e^{-y\theta^T x}\right)$$

**这正是 logistic loss！** 所以最小化 logistic loss = 让训练数据的概率尽可能大 = **最大似然估计（maximum likelihood）**。
- 这也解释了名字：用的是 logistic（sigmoid）函数
- 所以尽管叫"回归"，它是**分类模型**——"回归"指的是它在回归一个概率
- 额外好处：逻辑回归不仅给出类别，还给出**概率**（sklearn 中用 `model.predict_proba`）。θᵀx = 0 时概率正好 0.5，这就是决策边界。

## 5. 逻辑回归小结与梯度下降（Slide 10–11）

### 5.1 小结（Slide 10）
| | |
|---|---|
| 模型 | h_θ(x) = sign(θᵀx) |
| 参数 | θ |
| 代价函数 | J(θ) = (1/m) Σ log(1 + e^(−y⁽ⁱ⁾θᵀx⁽ⁱ⁾)) |
| 优化 | 选 θ 使 J(θ) 最小 |

### 5.2 求偏导数（推导过程）
课件提示用到三条规则：
- d log(x)/dx = 1/x
- d eˣ/dx = eˣ
- 链式法则：df(z(x))/dx = (df/dz)·(dz/dx)

对一个样本，令 z = y·θᵀx，则 ∂z/∂θⱼ = y·xⱼ（因为 θᵀx 中只有 θⱼxⱼ 这一项含 θⱼ）：

$$\frac{\partial}{\partial \theta_j}\log(1 + e^{-z}) = \underbrace{\frac{1}{1 + e^{-z}}}_{\text{log 的导数}} \cdot \underbrace{e^{-z}}_{\text{exp 的导数}} \cdot \underbrace{(-y x_j)}_{\partial(-z)/\partial\theta_j}$$

所以：

$$\frac{\partial J}{\partial \theta_j} = \frac{1}{m}\sum_{i=1}^{m} -y^{(i)} x_j^{(i)} \frac{e^{-y^{(i)}\theta^T x^{(i)}}}{1 + e^{-y^{(i)}\theta^T x^{(i)}}}$$

### 5.3 梯度下降算法
```
从某个 θ 开始
重复：
    for j = 0 到 n:  δⱼ := −α · ∂J/∂θⱼ
                        = +(α/m) Σᵢ y⁽ⁱ⁾ x⁽ⁱ⁾ⱼ · e^(−y⁽ⁱ⁾θᵀx⁽ⁱ⁾) / (1 + e^(−y⁽ⁱ⁾θᵀx⁽ⁱ⁾))
    for j = 0 到 n:  θⱼ := θⱼ + δⱼ
```

> ⚠️ **课件 Slide 11 中 δⱼ 的符号有误**：写的是 "δⱼ := −(α/m) Σ …"，但 ∂J/∂θⱼ 本身已经带了一个负号，−α × (负号) 应该得到**正号**。按课件的符号去实现会往上坡走，J 会越来越大。上面是修正后的版本。自己实现时可以用 "J 每步都应该下降"（Week 1 讲的调试方法）来检查。

**J(θ) 是凸的（convex），只有一个最小值**，梯度下降会一路往下走到最小值。

> 💡 **直观理解更新公式**：权重因子 e^(−z)/(1 + e^(−z)) = σ(−z)，取值在 0 到 1 之间：
> - 分错的点（z < 0）→ 权重接近 **1** → 对更新贡献大
> - 分对且有把握的点（z ≫ 0）→ 权重接近 **0** → 几乎不影响更新
>
> 每个样本把 θ 往 y·x 的方向推（让 y·θᵀx 变大），而且**越是分错的点推得越用力**。

## 6. Python sklearn：逻辑回归（Slide 12–13）

### 6.1 代码（已修正，可直接运行）
```python
import numpy as np
from sklearn.linear_model import LogisticRegression
import matplotlib.pyplot as plt

# ① 生成数据：x 在 [0,1] 均匀分布；x > 0.5 时 y = +1，否则 y = −1
Xtrain = np.random.uniform(0, 1, 100)
ytrain = np.sign(Xtrain - 0.5)
Xtrain = Xtrain.reshape(-1, 1)

# ② 训练（不加惩罚项）
model = LogisticRegression(penalty=None, solver='lbfgs')
model.fit(Xtrain, ytrain)
print("intercept %f, slope %f" % (model.intercept_[0], model.coef_[0, 0]))

# ③ 预测并画图
ypred = model.predict(Xtrain)
plt.rc('font', size=18)
plt.rcParams['figure.constrained_layout.use'] = True
plt.scatter(Xtrain, ytrain, color='red', marker='+', label='train')
plt.scatter(Xtrain, ypred, color='green', marker='+', label='predict')
plt.xlabel('input x'); plt.ylabel('output y')
plt.legend()
plt.show()
```

> ⚠️ 相对课件的修改：
> - `penalty='none'`（字符串）在新版 sklearn（1.4+）中已被移除，要写成 `penalty=None`
> - 课件的 `linear\_model` 多了反斜杠；弯引号 `’` `”` 和特殊减号 `−` 要换成普通字符
> - `intercept_` 是一维数组、`coef_` 是二维数组，用 `%f` 打印时最好取出具体元素 `[0]`、`[0, 0]`
> - 画图代码中 `ypred` 没有定义，需要 `ypred = model.predict(Xtrain)`
> - 两个 `scatter` 都用 `label=` 标注，比 `plt.legend([...])` 更不容易标错

### 6.2 结果解读
典型输出：intercept −267.03，slope 529.95

- 预测 ŷ = sign(−267.03 + 529.95x)
- 决策边界：−267.03 + 529.95x = 0 → **x = 267.03 / 529.95 ≈ 0.5039**
- x > 0.5039 预测 +1，x < 0.5039 预测 −1

数据是按 x > 0.5 → +1 生成的，所以学到的模型**大致正确，但不完美**。课件问："这很正常。为什么？"

> 💡 **为什么不正好是 0.5？**
> - 只有 100 个随机样本。在最靠近 0.5 的那个负样本和最靠近 0.5 的那个正样本之间有一个**空隙**，边界放在空隙里**任何位置**，训练数据都 100% 分对。模型没有任何信息可以知道空隙中哪个位置才是"真正的" 0.5。
> - 换一批随机数据，边界又会落在略微不同的位置——这就是有限数据带来的不确定性。
>
> 💡 **为什么系数这么大（几百）？**
> 数据是**线性可分**的，又没有惩罚项。对于线性可分的数据，把 θ 放大（比如 ×10）不会改变边界位置，但能让每个点的 z = y·θᵀx 都变大、logistic loss 进一步变小。所以优化器会一直把 θ 放大，直到达到迭代次数上限才停（可能会看到 ConvergenceWarning）。θ 很大意味着 sigmoid 非常陡——模型"过度自信"。这正是 SVM 部分（以及 Week 3 正则化）要加惩罚项的原因。

## 7. 多分类 Multiple Classes（Slide 14–15）

### 7.1 例子
- 邮件文件夹分类：工作、朋友、家人、爱好
- 天气：晴、多云、雨、雪
- 根据我在都柏林的住址，预测我会投票给哪个政党

y 现在取 0, 1, 2, …，例如 y = 0 晴，y = 1 多云，y = 2 雨。

### 7.2 方法：一对多（One-vs-Rest / One-vs-All）
把多分类拆成多个二分类：
- 对**每个类别 i**，训练一个二分类器 sign(θ⁽ⁱ⁾ᵀx)
- 训练时**重新标注**数据：y = i 的样本标为 +1，其他所有样本标为 −1
- 这样每个分类器都回到了熟悉的二分类问题，学的是"是不是第 i 类"（逻辑回归可以给出 y = i 的概率）

**预测时**：把新样本 x 分别送进 K 个分类器，选**最有把握说"是"的那个**，即 θ⁽ⁱ⁾ᵀx（或概率）最大的类别。

> 💡 例：3 类天气需要训练 3 个分类器：晴 vs 非晴、多云 vs 非多云、雨 vs 非雨。
>
> 💡 sklearn 细节：`LinearSVC` 默认用 one-vs-rest；`LogisticRegression` 在新版本中多分类时默认用另一种方法（multinomial / softmax，一次性同时训练所有类别），思想类似。

## 8. SVM：hinge loss（Slide 16–17）

### 8.1 Hinge loss
SVM（Support Vector Machine，支持向量机）使用 **hinge loss（合页损失）**：

$$\max(0,\ 1 - y\theta^T x)$$

还是用 z = y·θᵀx 来看：max(0, 1 − z)

| z = y·θᵀx | −2 | −1 | 0 | 0.5 | 1 | 2 | 3 |
|---|---|---|---|---|---|---|---|
| hinge loss | 3 | 2 | 1 | 0.5 | **0** | **0** | **0** |
| logistic loss（对比） | 3.07 | 1.9 | 1 | 0.68 | 0.45 | 0.18 | 0.07 |

形状像一扇打开的**合页**：z < 1 时是一条斜线，z ≥ 1 时平躺在 0。

（注：Slide 16 两张图的纵轴标签还写着 log(1+e^…)，应该是从上一页复制过来的，图里画的是 hinge loss。）

### 8.2 和 logistic loss 的主要区别（Slide 16）
1. **Hinge loss 不可导（non-smooth）**：在 z = 1 处有一个折角
2. **只要"足够正确"就完全不惩罚**：y = 1 时 θᵀx ≥ 1、y = −1 时 θᵀx ≤ −1，loss 就**正好等于 0**。而 logistic loss 永远 > 0，总是还想让 z 更大一点。

### 8.3 问题：可以作弊（Slide 17）
只要 y·θᵀx > 0（分类正确），把 θ 放大到 10θ 或 100θ，就总能让 y·θᵀx > 1，hinge loss 变成 0。所以单用 hinge loss，θ 可以无限放大而且"看起来很完美"，但这没有意义。

### 8.4 解决：加惩罚项
为了得到合理的行为，要**惩罚大的 θ**，加上：

$$\theta^T\theta = \sum_{j=1}^{n}\theta_j^2$$

（注意是从 j = 1 开始，截距 θ₀ 通常**不**惩罚。）

**最终的 SVM cost function：**

$$J(\theta) = \frac{1}{m}\sum_{i=1}^{m}\max\left(0,\ 1 - y^{(i)}\theta^T x^{(i)}\right) + \frac{\theta^T\theta}{C}$$

- **C > 0** 是一个需要我们自己选的**权重参数（超参数 hyperparameter）**
- **C 越大 → 惩罚项越不重要** → 允许更大的 θ → 更努力地把每个训练点都分对且 z ≥ 1（容易过拟合）
- **C 越小 → 惩罚越重** → θ 更小 → 允许一些点违反 margin（更"宽松"，更平滑）

> 💡 **【拓展】几何意义：最大间隔（maximum margin）**
> 两条平行线 θᵀx = +1 和 θᵀx = −1 之间的区域叫做 **margin（间隔）**，它的宽度 = 2 / ‖θ‖（‖θ‖ 是不含 θ₀ 的 θ 的长度）。
> - hinge loss 要求每个点都在 margin **之外**的正确一侧（z ≥ 1）
> - 惩罚 θᵀθ = ‖θ‖² → 让 ‖θ‖ 小 → 让 margin **宽**
>
> 所以 SVM 在找的是：**能把两类分开、并且离两边的点都尽可能远的那条边界**。直觉上这样的边界最"稳"，对新数据泛化更好。

---

## 9. SVM 小结与支持向量（Slide 18）

| | |
|---|---|
| 模型 | h_θ(x) = sign(θᵀx) |
| 参数 | θ |
| 代价函数 | J(θ) = (1/m) Σ max(0, 1 − y⁽ⁱ⁾θᵀx⁽ⁱ⁾) + θᵀθ/C |
| 优化 | 选 θ 使 J(θ) 最小 |

**观察**：和逻辑回归**唯一的区别就是 cost function**。

SVM cost function 的两个特点：
1. **包含惩罚项 θᵀθ/C**。但这不是 SVM 独有的——逻辑回归也可以加这样的惩罚项，这叫做**正则化（regularisation）**，Week 3 会讲。（sklearn 的 `LogisticRegression` 默认其实就加了，所以第 6 节才要特意写 `penalty=None`。）
2. **对 y⁽ⁱ⁾θᵀx⁽ⁱ⁾ ≥ 1 的点，求和中的项为 0** ← **这才是最重要的区别**
   - 这些训练点**对 cost function 没有任何贡献**，把它们删掉，结果完全一样
   - 只有 y⁽ⁱ⁾θᵀx⁽ⁱ⁾ < 1 的点（在 margin 之内或分错的点）才有影响 → 这些点叫**支持向量（support vectors）**，SVM 由此得名
   - 好处：计算可以更高效

> 💡 **直观理解**：决策边界完全由"靠近边界的困难样本"决定，离边界很远、很容易分的样本不起作用。而逻辑回归中每个点都有（哪怕很小的）贡献。

## 10. SVM 的次梯度下降（Slide 19）

hinge loss 在 z = 1 处不可导，所以用**次梯度（subgradient）**：在折角处随便取一个合理的斜率即可，其他地方就是普通导数。

max(0, 1 − y·θᵀx) 对 θⱼ 的（次）导数：
- 若 y·θᵀx < 1（在斜线部分）：−y·xⱼ
- 若 y·θᵀx > 1（在平躺部分）：0

θᵀθ/C 对 θⱼ 的导数：2θⱼ/C

**次梯度下降算法：**
```
从某个 θ 开始
重复：
    for j = 0 到 n:  δⱼ := −α · ( 2θⱼ/C − (1/m) Σᵢ y⁽ⁱ⁾ x⁽ⁱ⁾ⱼ · 𝟙(y⁽ⁱ⁾θᵀx⁽ⁱ⁾ ≤ 1) )
    for j = 0 到 n:  θⱼ := θⱼ + δⱼ
```
- **𝟙(条件)** 是指示函数：条件成立为 1，否则为 0（课件里显示成 "/x31" 是 PDF 字体问题，就是这个 𝟙 符号）
- 所以求和里**只有支持向量**（y·θᵀx ≤ 1 的点）参与
- 2θⱼ/C 这一项每步都把 θ 往 0 拉一点（"权重衰减"）
- 严格来说，如果惩罚项不含 θ₀，那么 j = 0 时应去掉 2θ₀/C 这一项

**J(θ) 是凸的，只有一个最小值**，迭代会一路往下走到最小值。

## 11. Python sklearn：SVM（Slide 20）

（课件这页标题写的是 "Logistic regression"，实际代码是 SVM。沿用第 6 节的 `Xtrain`、`ytrain`。）

```python
from sklearn.svm import LinearSVC
model = LinearSVC(C=1.0).fit(Xtrain, ytrain)
print("intercept %f, slope %f" % (model.intercept_[0], model.coef_[0, 0]))
```

### 11.1 结果对比
| 模型 | intercept | slope | 决策边界 x = −intercept/slope |
|---|---|---|---|
| Logistic Regression（无惩罚） | −267.03 | 529.95 | 0.5039 |
| **SVM, C = 1** | −1.89 | 3.87 | **0.4888** |
| **SVM, C = 1000** | −19.83 | 40.27 | **0.4924** |

**解读：**
- 惩罚项让 SVM 选择**小得多的 θ**（3.87 vs 529.95）
- **C 变大 → 惩罚变轻 → θ 变大**（3.87 → 40.27），边界也更接近逻辑回归的结果
- C = 1 时惩罚较重，模型宁可让边界附近的少数点违反 margin，也要保持 θ 小，所以边界偏离得更多
- **C 是一个需要选择的超参数**——怎么选？→ Week 3 cross-validation

> 💡 sklearn 细节：`LinearSVC` 默认用的是 **squared hinge**（hinge 的平方）而不是课件的 hinge，而且 C 的位置写法略有不同（sklearn 是 C × loss + 惩罚，课件是 loss + 惩罚/C），但"C 越大、惩罚越不重要"的方向是一致的。想用标准 hinge 可以写 `LinearSVC(C=1.0, loss='hinge')`。

## 12. 三种 loss 对比总结

| | 平方误差 | Logistic loss | Hinge loss |
|---|---|---|---|
| 公式（z = y·θᵀx） | (θᵀx − y)² = (1 − z)² | log(1 + e^(−z)) | max(0, 1 − z) |
| 分对且很有把握（z 很大） | ❌ 反而惩罚很大 | 接近 0 | **正好 0** |
| 分错（z < 0） | 惩罚 | 约线性增长 | 线性增长 |
| 可导？ | 是 | 是（光滑） | 否（z = 1 处有折角） |
| 凸？ | 是 | 是 | 是 |
| 用于 | 线性回归 | 逻辑回归 | SVM |
| 哪些点影响结果 | 所有点 | 所有点（远点影响极小） | **只有支持向量** |
| 概率输出 | 否 | **是**（sigmoid） | 否 |

## 13. 本讲知识结构总结

```
二分类：y ∈ {−1, +1}，模型 sign(θᵀx)，决策边界 θᵀx = 0（点/线/超平面）
    │
    ├─ 关键量：margin z = y·θᵀx（> 0 分对，越大越有把握）
    │
    ├─ 选 cost function
    │     ├─ 平方误差 ✗：惩罚"太正确"的点，边界被远处的点拽偏
    │     ├─ 0-1 loss ✗：就是错误率，但导数处处为 0，没法优化
    │     ├─ Logistic loss ✓ → 逻辑回归
    │     │     ├─ 光滑、凸 → 梯度下降（注意课件 δⱼ 符号笔误）
    │     │     └─ 等价于最大似然，可以输出概率（sigmoid）
    │     └─ Hinge loss + θᵀθ/C ✓ → SVM
    │           ├─ z ≥ 1 的点 loss = 0 → 只有支持向量起作用
    │           ├─ 必须加惩罚项，否则放大 θ 就能"作弊"
    │           ├─ 几何上 = 最大化 margin
    │           ├─ 不可导 → 次梯度下降
    │           └─ C 越大惩罚越轻、θ 越大
    │
    ├─ 多分类：one-vs-rest，K 个二分类器，选最有把握的那个
    │
    └─ 逻辑回归 vs SVM：模型相同，只有 cost function 不同
```

## 15. 自测问题

1. 决策边界 3 − x₁ + x₂ = 0 是什么形状？点 (0, 0) 会被预测为哪一类？
2. y = −1，θᵀx = 2.5，这个点分对了吗？z = y·θᵀx 是多少？
3. 为什么平方误差不适合分类？用一个具体的点说明。
4. 为什么不直接最小化 0-1 loss（错误率）？
5. logistic loss 在 z = 0 时等于多少（除以 log 2 后）？z 很大时呢？
6. 逻辑回归训练线性可分数据且不加惩罚时，为什么系数会变得非常大？
7. SVM 中如果去掉 θᵀθ/C 惩罚项会怎样？
8. 什么是支持向量？删掉一个 y·θᵀx = 5 的训练点，SVM 的结果会变吗？逻辑回归呢？
9. SVM 的 C 从 1 增加到 1000，θ 会变大还是变小？为什么？
10. 用 one-vs-rest 做 4 分类，需要训练几个分类器？每个分类器的训练标签怎么设？

<details>
<summary>点击查看参考答案</summary>

1. 两个特征 → 一条直线（x₂ = x₁ − 3）。代入 (0,0)：3 − 0 + 0 = 3 > 0 → 预测 +1。
2. θᵀx > 0 → 预测 +1，但真实是 −1 → 分错了。z = −1 × 2.5 = −2.5 < 0。
3. 平方误差要求 θᵀx 尽量等于 ±1。例如 y = +1、θᵀx = 5 的点分得完全正确，但平方误差 (5 − 1)² = 16 很大，优化时会为了减小它而移动边界，导致边界附近的点被分错。
4. 0-1 loss 是阶梯函数，导数几乎处处为 0（跳变处不可导），梯度下降无法知道往哪个方向调整；直接求解是 NP-hard 的组合问题。
5. z = 0 时 loss = 1；z 很大时趋近于 0（但不等于 0）。
6. 线性可分时，放大 θ 不改变边界，却能让所有点的 z 都变大、loss 继续变小，所以没有有限的最优解，优化器会一直把 θ 放大直到达到迭代上限。
7. 只要能分对，把 θ 放大就能让所有 z ≥ 1、hinge loss = 0，θ 可以无限大，cost function 没有合理的最小值。
8. 支持向量是 y·θᵀx < 1（在 margin 内或分错）的训练点，只有它们对 SVM 的 cost 有贡献。删掉一个 z = 5 的点 SVM 结果不变（它的 hinge loss 本来就是 0）；逻辑回归会有极微小的变化（它的 logistic loss ≈ 0.007，不是 0）。
9. 变大。C 越大，惩罚项 θᵀθ/C 越小越不重要，模型更愿意用大的 θ 把训练点推到 z ≥ 1。
10. 4 个。第 i 个分类器：y = i 的样本标为 +1，其余所有样本标为 −1。

## 16. 【拓展】课件留的练习：用 0/1 标签代替 ±1

课件脚注说"也可以用 0 和 1 作为标签，留作练习"。建议先自己试着推导，再看下面的提示。

<details>
<summary>点击查看提示与答案</summary>

用 y ∈ {0, 1}，模型给出 P(y = 1 | x) = σ(θᵀx)，P(y = 0 | x) = 1 − σ(θᵀx)。

一个样本的 −log 概率可以合写为：

$$-\left[\,y \log \sigma(\theta^T x) + (1 - y)\log\left(1 - \sigma(\theta^T x)\right)\right]$$

（y = 1 时只剩第一项，y = 0 时只剩第二项。）这就是常见的 **交叉熵损失（cross-entropy loss）** 写法，神经网络部分会经常见到。它和 ±1 标签下的 log(1 + e^(−yθᵀx)) 其实是**同一个函数**，只是标签编码方式不同。

此时梯度有一个特别简洁的形式：

$$\frac{\partial J}{\partial \theta_j} = \frac{1}{m}\sum_{i=1}^{m}\left(\sigma(\theta^T x^{(i)}) - y^{(i)}\right)x_j^{(i)}$$

和线性回归的梯度（Week 1）形式几乎一样：（预测 − 真实）× 特征，只是预测值换成了 σ(θᵀx)。

决策规则：σ(θᵀx) > 0.5 ⟺ θᵀx > 0 → 预测 1。所以决策边界还是 θᵀx = 0。
</details>
