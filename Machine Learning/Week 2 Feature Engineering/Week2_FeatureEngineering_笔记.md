## 0. 这一讲在讲什么？

课件第 1 页列了三个主题：
1. **特征工程（Feature engineering）**：怎样变换输入，让一个**线性模型**也能拟合**弯曲的**关系
2. **变换模型输出（Mapping model output）**：不光输入可以变换，输出也可以
3. **过拟合与欠拟合（Over-fitting and under-fitting）**：特征越多就越好吗？不是！

> 💡 本讲的核心一句话：**"线性模型"只要求对参数 θ 是线性的，特征 x 可以是原始输入的任何非线性函数。** 这让简单的线性模型变得非常灵活——但灵活过头就会过拟合。

---

## 1. 用线性模型拟合非线性曲线？（Slide 2）

回顾线性模型：
- 回归：ŷ = θᵀx
- 分类：ŷ = sign(θᵀx)

**为什么叫"线性"？** 把 θᵀx 对 x 作图：
- 1 个特征 → 一条**直线**
- 2 个特征 → 一个**平面**
- 超过 2 个特征 → 一个**超平面（hyperplane）**

看起来很受限——现实中的关系常常是弯的。但关键在于：**我们可以自由选择怎样把原始输入变成特征 x**。

> 💡 区分两个概念：
> - **原始输入（raw input）**：你拿到的数据，比如 TV 预算、图片像素、一段文字
> - **特征（features）x**：真正喂给模型的那些数字，可以由原始输入**计算**出来
>
> 模型对"特征"是线性的，但对"原始输入"可以是非线性的。

## 2. 例子：用圆形分开两类（分类）（Slide 3）

### 2.1 问题
- 两个特征 x₁、x₂，标签是 ±1
- 两类数据**不能被一条直线分开**（不是 linearly separable），而是被一个**圆**分开：圆内是一类，圆外是另一类（左图）

### 2.2 解决办法
圆的方程：x₁² + x₂² = R²（课件写成 "RR" 是排版问题，意思是 R²）

**换特征**：
- x₁ⁿᵉʷ = x₁²
- x₂ⁿᵉʷ = x₂²

模型变成：

$$\text{sign}(\theta_0 + \theta_1 x_1^{new} + \theta_2 x_2^{new})$$

这对新特征来说是**线性**的！例如取 θ₀ = −R², θ₁ = θ₂ = 1，就正好是 sign(x₁² + x₂² − R²)：圆外 +1，圆内 −1。

右图：把数据画在新特征 (x₁², x₂²) 的坐标系里，原来的圆变成了一条**直线**，两类数据可以用直线分开了。

> 💡 这是一个非常重要的思想：**原空间里分不开的数据，换到一个合适的特征空间里可能就能用直线分开。** 以后学的核方法（kernel methods）和神经网络本质上都是在自动寻找这种"好的特征空间"。

## 3. 例子：拟合二次曲线（回归）（Slide 4）

- 数据由输入 x 的**二次函数**加噪声生成
- 定义新特征 xⁿᵉʷ = x²
- **xⁿᵉʷ 可以直接从 x 算出来，所以它是已知的**（这点很重要：新特征必须能从已知输入算出）
- 模型变成 h_θ(xⁿᵉʷ) = θ₀ + θ₁xⁿᵉʷ，对 xⁿᵉʷ 是线性的

之后就可以**直接用 Week 1 学的线性回归**（最小二乘 + 梯度下降或 sklearn）来求 θ，方法完全不用改。

> 💡 实际中通常会**同时保留 x 和 x²**：h = θ₀ + θ₁x + θ₂x²，让模型自己决定每项的权重。如果数据其实不需要 x 项，训练出来 θ₁ 会接近 0。

## 4. 特征工程的基本思路（Slide 5）

### 4.1 流程
1. 从一些原始特征开始
2. 对它们**处理或变换**，产生新的（"工程化的 engineered"）特征
3. 在模型中使用这些新特征

### 4.2 怎么知道这样做好不好？
- 用**原始特征**训练模型 → 评估性能
- 用**新特征**训练模型 → 评估性能
- **比较两者**（例如比较 cost function 的值）

课件说 "much more on this shortly"——Week 3 的 **cross-validation（交叉验证）** 和 **evaluation（性能评估）** 会详细讲怎么公平地比较。

> ⚠️ 联系 Intro 的教训：比较时要看**模型没见过的数据**上的表现，而不是训练数据。否则加更多特征几乎总是让训练误差下降（第 9 节会看到这正是过拟合的陷阱）。

## 5. 常见的特征工程手段（Slide 6）

| 类型 | 做法 | 例子 |
|---|---|---|
| **修改单个特征** | 对一个特征做变换 | 归一化：xᵢⁿᵉʷ = (xᵢ − μᵢ)/σᵢ（μᵢ、σᵢ 是**训练数据**中 xᵢ 的均值、标准差）；也可以取 log、开方等 |
| **一个特征 → 多个特征** | 从一个特征生成多个 | **多项式/幂次**：把 xᵢ 替换成 (xᵢ, xᵢ², xᵢ³, …, xᵢ^q) |
| **多个特征 → 一个新特征** | 组合多个原始特征 | **乘积**：xⁿᵉʷ = xⱼ·xₖ |

> 💡 sklearn 里有现成工具：`sklearn.preprocessing.PolynomialFeatures`（生成幂次项和乘积项）、`StandardScaler`（标准化）、`MinMaxScaler`（缩放到 [0,1]）。
>
> ⚠️ 用高次幂时**一定要先归一化**！比如 TV 预算最大约 300，300¹⁰ ≈ 5.9×10²⁴，数值会爆炸（回顾 Week 1 Linear Regression 第 13 节）。

## 6. 乘积特征与交互作用（Slide 7）

### 6.1 为什么用乘积？
乘积可以表达**特征之间的交互作用（interaction）**：两个因素**同时出现**时的效果，不等于它们各自效果之和。

### 6.2 例子
假设 x₁、x₂、x₃ 都是**布尔值（0 或 1）**，比如：
- 病人是否有某种症状
- 购物篮里是否有某件商品

模型：

$$\hat{y} = \theta_1 x_1 + \theta_2 x_2 + \theta_3 x_3 + \theta_4 x_1 x_2 + \theta_5 x_1 x_3 + \theta_6 x_2 x_3$$

**参数的含义**：
- **θ₁**：x₁ = 1 时预测值增加多少（θ₂、θ₃ 同理）
- **θ₄**：x₁ 和 x₂ **都**等于 1 时，**额外**增加多少（因为 x₁x₂ 只有在两者都是 1 时才等于 1）
- **θ₅**：x₁ 和 x₃ 都为 1 时的额外增量
- **θ₆**：x₂ 和 x₃ 都为 1 时的额外增量

> ⚠️ 课件最后一句写成了 "θ₅ when x₂ = 1 and x₃ = 1"，应该是 **θ₆**。

### 6.3 具体算一下（帮助理解"额外"的含义）
| x₁ | x₂ | x₃ | ŷ |
|---|---|---|---|
| 1 | 0 | 0 | θ₁ |
| 0 | 1 | 0 | θ₂ |
| 1 | 1 | 0 | θ₁ + θ₂ + **θ₄** |

所以 θ₄ 衡量的是"两者一起出现"比"各自效果简单相加"多出来（或少了）多少：
- θ₄ > 0：**协同效应**（1 + 1 > 2），比如 Week 1 广告数据中 TV 和 Radio 一起投放
- θ₄ < 0：两者效果有**重叠/抵消**（1 + 1 < 2），比如两种作用相同的药
- θ₄ ≈ 0：两者独立，没有交互

> 💡 这个模型课件没写截距 θ₀，实际使用时通常会加上。

## 7. 变换输出：Covid 例子（Slide 8–9）

### 7.1 思路
我们不仅可以变换**输入→特征**，也可以变换**模型输出→我们真正关心的量**。

### 7.2 指数增长模型
传染病（比如 Covid）在人群中的传播常用**指数增长（exponential growth）**来建模：

$$z_k = e^{ak} z_0$$

- zₖ：第 k 天的感染人数
- z₀：第 0 天的感染人数
- a：增长参数。a > 0 → 增长；a < 0 → 衰减

这个关系对 k 是**非线性**的（指数曲线）。

### 7.3 取对数变成线性
两边取 log：

$$\log z_k = ak + \log z_0$$

定义模型输出 yₖ = log zₖ（所以 y₀ = log z₀），得到：

$$y_k = ak + y_0 = \theta_1 k + \theta_0$$

这是一个标准的线性模型！θ₁ = a（增长率），θ₀ = log z₀。直接用线性回归就能从数据中估计。

**完整流程**：
1. 把每天的病例数 zₖ 取 log，得到 yₖ
2. 对 (k, yₖ) 做线性回归，得到 θ₀、θ₁
3. 要预测病例数时，再**变换回来**：ẑₖ = e^(θ₀ + θ₁k)

### 7.4 爱尔兰的真实数据（Slide 9）
- 数据：2020 年 3 月 3 日起爱尔兰的 Covid 病例数
- 左图：原始病例数 vs 天数 → 明显的指数型上升曲线
- 右图：log(病例数) vs 天数 → 大致是一条**直线**；红色虚线是在变换后数据上拟合的线性回归

> 💡 拓展理解：
> - 取 log 后数据接近直线，本身就是"增长是指数型"的证据
> - 从 a 可以算出**翻倍时间（doubling time）** = ln 2 / a 天
> - 在 log 尺度上做最小二乘，相当于惩罚的是**相对误差**（比例误差）而不是绝对误差，这对跨越几个数量级的数据更合理
> - 在实际疫情中，封控措施等会改变 a，所以一条直线不会永远适用——右图后段如果开始偏离直线，就说明增长率变了

## 8. 人工特征 vs 自动特征（Slide 10）

- **人工设计（hand-crafted）**：特征选择和特征工程通常**靠人手做**，依靠对任务的理解和经验——这是机器学习中"**艺术**"的部分。前面的圆形、x²、log 变换都是这类例子。
- **自动学习（automatic）**：也可以从数据中**训练**出特征映射，例如：
  - **word2vec**：把每个词映射成一个向量，意思相近的词向量也相近（比 Intro 的 bag of words 更有表达力）
  - **VGG16**：一个在超大图片数据集上训练好的神经网络，它的中间层可以作为图片的特征
  - 这两个都是从**非常大的数据集**上自动得到的，课程后面（深度学习部分）会讲
- 自动方法的缺点：**很难做对，而且非常耗时**

## 9. 模型选择：为什么不把所有可能的特征都加进去？（Slide 11–12）

### 9.1 实验（Slide 11）
用 Week 1 的广告数据（TV → Sales），但**只取每第 10 个点**（数据变少，只剩 20 个点左右），试几个模型：

| 模型 | 参数个数 |
|---|---|
| h = θ₀ + θ₁x（直线） | 2 |
| h = θ₀ + θ₁x + θ₂x²（二次） | 3 |
| h = θ₀ + θ₁x + … + θ₆x⁶（6 次） | 7 |
| h = θ₀ + θ₁x + … + θ₁₀x¹⁰（10 次） | 11 |

**观察结果**：
- 参数越多，曲线越弯，越"努力"地穿过每一个训练点
- 6 次、10 次多项式开始**拟合训练数据里的噪声**，而不是真实的规律 → 这叫**过拟合（overfitting）**
- 在**没有训练数据的地方**（点与点之间的空隙、数据范围的边缘），高次模型的预测变得**非常离谱**（曲线大幅上下摆动，甚至预测出负销量）→ 模型**泛化（generalise）**能力很差

> 💡 **泛化（generalisation）**：模型在**没见过的新数据**上表现如何。这才是机器学习真正关心的。训练误差小不代表泛化好。
>
> 💡 为什么高次多项式会乱摆？10 次多项式有 11 个参数，20 个点对它来说约束太少，它有足够的自由度去"迎合"每个点的随机噪声，代价是在点之间剧烈弯曲。极端情况：m 个点，用 m−1 次多项式可以**完美穿过所有点**（训练误差为 0），但几乎肯定泛化很差。这和 Intro 里"参数比数据多，训练准确率 100%"是同一件事。

### 9.2 更多数据有帮助（Slide 12）
- 用**全部**数据（不抽稀）：左图中各模型在数据范围内都差不多，高次模型的乱摆被压住了 → **更多数据可以缓解过拟合**
- 但右图把横轴扩展到 −100 到 500（**超出训练数据范围**）：高次模型在范围外仍然**飞得很离谱**
- 结论：即使数据更多，复杂模型对训练集范围**以外**的数据依然预测很差（回顾 Week 1 的**外推 extrapolation** 风险）

## 10. 欠拟合与偏差-方差权衡（Slide 13）—— 本讲最重要的概念

### 10.1 两个极端
| | 过拟合 Overfitting | 欠拟合 Underfitting |
|---|---|---|
| 原因 | 模型**太复杂** | 模型**太简单** |
| 表现 | 训练误差很小，新数据上误差大 | 训练误差和新数据误差**都**大 |
| 本质 | 学到了噪声 | 连真实规律都没学到 |
| 例子 | 用 10 次多项式拟合 20 个点 | 数据是二次的，却用直线去拟合 |
| 比喻 | 死记硬背考题的学生，换题就不会 | 根本没学会的学生，原题也做不对 |

### 10.2 核心任务
**在过拟合和欠拟合之间找到平衡**，是监督学习的一个核心任务，而且是**所有**监督学习方法**本质上都有、无法回避**的问题。

### 10.3 偏差-方差权衡（Bias-Variance Trade-off）
这就是这个问题的另一个名字。直观解释：

- **偏差（Bias）**：模型**本身的假设**离真实规律有多远。
  - 用直线去拟合弯曲的数据，不管给多少数据都拟合不好 → **高偏差** → 欠拟合
- **方差（Variance）**：模型对**训练数据的具体取样**有多敏感。
  - 10 次多项式：换一批训练数据（噪声不同），拟合出的曲线会完全不一样 → **高方差** → 过拟合
- **权衡（trade-off）**：模型越复杂 → 偏差越低，但方差越高；模型越简单 → 方差越低，但偏差越高。我们要找的是两者加起来总误差最小的那个"中间复杂度"。

```
误差
 │ ╲                          ╱  ← 新数据上的误差（先降后升）
 │  ╲                       ╱
 │   ╲___               ___╱
 │       ╲_____________╱
 │ ─────────────────────────── ← 训练误差（一直下降）
 │ 欠拟合      最佳       过拟合
 └──────────────────────────────→ 模型复杂度（如多项式次数）
   高偏差                  高方差
```

> 💡 怎么找到"最佳"复杂度？→ Week 3 的 **cross-validation（交叉验证）**。另一个办法是 **regularisation（正则化）**：保留复杂模型但惩罚过大的参数（Week 2 SVM 那讲的 θᵀθ/C 就是一个例子，Week 3 也会细讲）。

## 11. 本讲知识结构总结

```
线性模型 θᵀx：对 θ 线性，对原始输入可以非线性
    │
    ├─ 变换输入（特征工程）
    │     ├─ 单个特征变换：归一化、log……
    │     ├─ 一变多：x → x, x², ..., x^q（多项式）
    │     ├─ 多变一：xⱼ·xₖ（交互项，表达协同效应）
    │     └─ 例：圆形边界 → 用 x₁², x₂² 变成线性可分
    │
    ├─ 变换输出
    │     └─ 例：Covid 指数增长 → 取 log → 线性回归 → 再 exp 回去
    │
    ├─ 人工特征（经验）vs 自动特征（word2vec、VGG16）
    │
    └─ 模型选择：特征不是越多越好
          ├─ 太复杂 → 过拟合（高方差）→ 拟合噪声、泛化差
          ├─ 太简单 → 欠拟合（高偏差）→ 连规律都没学到
          ├─ 更多数据可以缓解过拟合，但解决不了外推问题
          └─ 偏差-方差权衡：所有监督学习都绕不开 → Week 3 交叉验证
```

## 13. 自测问题

1. 模型 ŷ = θ₀ + θ₁x + θ₂x² + θ₃ sin(x) 算线性模型吗？为什么？
2. 数据被一个以原点为中心、半径为 2 的圆分开（圆内 −1、圆外 +1）。用什么特征能让它线性可分？对应的 θ 大概是什么？
3. 在第 6 节的布尔特征模型中，如果 x₁ = x₂ = x₃ = 1，预测值是多少？
4. 如果估计得到 Covid 增长参数 a = 0.1（每天），病例大约多少天翻一倍？
5. 为什么用 10 次多项式时要先对 x 归一化？
6. 某模型训练误差很小，但在新数据上误差很大，这是什么问题？是高偏差还是高方差？
7. 某模型训练误差和新数据误差都很大，这是什么问题？应该让模型更复杂还是更简单？
8. 增加训练数据能解决过拟合吗？能解决欠拟合吗？

<details>
<summary>点击查看参考答案</summary>

1. 算。它对参数 θ 是线性的：把 x、x²、sin(x) 看成三个特征，模型就是 θᵀx。
2. 用 x₁²、x₂² 作特征。圆的方程 x₁² + x₂² = 4，所以取 θ₀ = −4, θ₁ = θ₂ = 1：sign(x₁² + x₂² − 4)，圆外为 +1，圆内为 −1。
3. θ₁ + θ₂ + θ₃ + θ₄ + θ₅ + θ₆（所有乘积项都等于 1）。
4. 翻倍时间 = ln 2 / a ≈ 0.693 / 0.1 ≈ 6.9 天。
5. x 的高次幂数值差距极大（例如 300¹⁰ ≈ 10²⁵），会造成数值问题，并且数值大的特征会主导 cost function 和梯度，梯度下降难以收敛。
6. 过拟合，高方差。
7. 欠拟合，高偏差。应该让模型更复杂（例如加入 x² 等特征）。
8. 更多数据通常能缓解过拟合（噪声被"平均掉"，复杂模型也不容易乱摆）。但不能解决欠拟合——模型本身太简单，数据再多也拟合不好，需要换更复杂的模型或更好的特征。
</details>
