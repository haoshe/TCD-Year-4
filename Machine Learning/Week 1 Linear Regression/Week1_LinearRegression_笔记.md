## 3. 记号 Notation（Slide 4）—— 一定要记熟

| 记号 | 含义 |
|---|---|
| **m** | 训练样本的数量（这里 m = 200） |
| **x** | 输入变量 / 特征（input variable / feature），这里是 TV 预算 |
| **y** | 输出变量 / 目标变量（output / target），这里是 Sales |
| **(x⁽ⁱ⁾, y⁽ⁱ⁾)** | 第 i 个训练样本 |

例：x⁽¹⁾ = 230.1, y⁽¹⁾ = 22.1；x⁽²⁾ = 44.5, y⁽²⁾ = 10.4

> ⚠️ **上标 (i) 不是 i 次方！** 它只是"第 i 个样本"的编号。加括号就是为了和次方区分开。
> 后面还会出现下标：x⁽ⁱ⁾ⱼ = 第 i 个样本的第 j 个特征。**上标看是哪个样本，下标看是哪个特征。**

## 4. 模型（Slide 5）

$$\hat{y} = h_\theta(x) = \theta_0 + \theta_1 x$$

- 这就是中学学的直线 y = mx + c：
  - **θ₀ 是截距（intercept）**：x = 0 时的预测值（完全不打广告时的销量）
  - **θ₁ 是斜率（slope）**：x 每增加 1，预测值增加多少（每多花 1 单位 TV 预算，销量多多少）
- θ₀、θ₁ 是**未知参数（parameters）**，要从数据中学出来
- h_θ(x) 的下标 θ 表示"这个函数由 θ 决定"，平时常简写为 h(x)

Slide 5 的三张图展示了不同参数下的直线：
| 参数 | 直线 | 含义 |
|---|---|---|
| θ₀ = 15, θ₁ = 0 | 水平线 y = 15 | 不管广告多少都预测 15，忽略了 x |
| θ₀ = 0, θ₁ = 0.1 | 过原点的斜线 | 截距太低 |
| θ₀ = 15, θ₁ = 0.1 | 高一些的斜线 | 截距太高，整条线都偏高（注意这张图纵轴到 50） |

三条都拟合得不好 → 我们需要一个**系统的方法**来选出最好的 θ₀、θ₁。这就是下一节的 cost function。

## 5. 代价函数 Cost Function（Slide 6）

### 5.1 思路
选 θ₀、θ₁，使得对每一个训练样本，预测值 h_θ(x⁽ⁱ⁾) 都**尽量接近**真实值 y⁽ⁱ⁾。

### 5.2 最小二乘（Least Squares）

$$J(\theta_0, \theta_1) = \frac{1}{m}\sum_{i=1}^{m}\left(h_\theta(x^{(i)}) - y^{(i)}\right)^2$$

逐个拆开理解：
- h_θ(x⁽ⁱ⁾) − y⁽ⁱ⁾：第 i 个点的**预测误差**（预测值 − 真实值）
- (...)²：平方，这样正误差和负误差都变成正数，不会互相抵消；而且**大误差被放大**（误差 2 → 4，误差 10 → 100）
- Σ 求和然后 × 1/m：所有点的平方误差取**平均**
- 这个量也叫 **MSE（Mean Squared Error，均方误差）**

**目标：找到使 J(θ₀, θ₁) 最小的 θ₀、θ₁。**

> 💡 **J 是 θ 的函数，不是 x 的函数！** 这是初学者最容易搞混的地方。训练数据 x⁽ⁱ⁾、y⁽ⁱ⁾ 是固定的已知数字；我们调整的是 θ。每换一组 (θ₀, θ₁)，就得到一条不同的直线，就算出一个不同的 J 值。

### 5.3 另一种写法
J 是每个训练点误差的总和，所以也可以写成：

$$J(\theta_0, \theta_1) = \frac{1}{m}\sum_{i=1}^{m} l_i(\theta_0, \theta_1), \quad l_i(\theta_0,\theta_1) = \left(h_\theta(x^{(i)}) - y^{(i)}\right)^2$$

l_i 是**单个样本的损失（loss）**。这个写法以后会用到：cost function = 每个样本 loss 的平均。以后换不同的 loss（比如逻辑回归的 loss），整体框架不变。

## 6. 一个简单的例子（Slide 7）—— 手算帮助理解

### 6.1 题目
训练数据只有两个点：(3, 1) 和 (2, 1)，并且已知 θ₀ = 0（直线过原点）。所以模型是 h(x) = θ₁x，只有一个参数 θ₁。

cost function：

$$J(\theta_1) = \frac{1}{2}\left[(1 - 3\theta_1)^2 + (1 - 2\theta_1)^2\right]$$

> ⚠️ 课件上写的是 (y⁽ʲ⁾ **+** θ₁x⁽ʲ⁾)²，这是**笔误**，应该是**减号**：(θ₁x − y)² = (y − θ₁x)²。后面展开式 (1 − 3θ₁)² 是对的。

### 6.2 求解（课件问的问题）
求导并令导数为 0（最小值处斜率为 0）：

$$\frac{dJ}{d\theta_1} = \frac{1}{2}\left[2(1-3\theta_1)(-3) + 2(1-2\theta_1)(-2)\right] = -3 + 9\theta_1 - 2 + 4\theta_1 = 13\theta_1 - 5$$

令 13θ₁ − 5 = 0 → **θ₁ = 5/13 ≈ 0.385**

课件里的图画的就是 J(θ₁) 随 θ₁ 变化的曲线：一个**开口向上的抛物线（U 形）**，最低点大约在 θ₁ ≈ 0.38。

> 💡 直观检查：两个点 (3,1) 和 (2,1)，一个需要斜率 1/3 ≈ 0.33，一个需要斜率 1/2 = 0.5 才能完美穿过。最终结果 0.385 在两者之间，偏向 0.33——因为 x = 3 的点误差被 θ 放大得更多，对 J 影响更大。合理！

## 7. 广告数据的 cost function 长什么样（Slide 8）

对于真实的广告数据，J(θ₀, θ₁) 有两个参数，所以画出来是一个 **3D 曲面**：两个水平轴是 θ₀、θ₁，竖轴是 J。

它的形状是一个**碗（bowl）**：
- 碗底 = J 的最小值 = 最好的那条直线
- 线性回归 + 最小二乘的 J **永远是碗形**（数学上叫**凸函数 convex**），只有一个最低点。这是个非常好的性质（见第 10 节）。

## 8. 残差 Residuals（Slide 9）

### 8.1 定义
**残差（residual）= 真实值 − 模型预测值**，即每个数据点离拟合直线在竖直方向上的距离。

Slide 9 左图：数据点 + 最小二乘拟合出的直线；右图：每个点的残差 vs TV 预算。

### 8.2 为什么要看残差？—— 用来检验模型是否合适
讲师问："残差看起来是**随机的**，还是有**某种结构**？"

- **如果模型是合适的**：残差应该像随机噪声一样，在 0 上下均匀、无规律地分布
- **如果残差有明显规律（structure）**，说明模型漏掉了什么：
  - 残差呈**曲线形**（比如两头正、中间负）→ 真实关系可能是弯的，直线不够
  - 残差**越往右越散开（喇叭形 / 扇形）**→ 误差大小随 x 变化，TV 预算高时预测更不确定
- 对于这份 TV 广告数据，残差确实随 TV 预算增大而**越来越分散**，并且有点弯曲，说明简单直线模型并不完美。

### 8.3 其他用途
可以用残差估计预测的**置信区间（confidence interval）**：残差大致有多大，就说明预测大概会差多少。

## 9. 小结：单特征线性回归（Slide 10）

| | |
|---|---|
| 特征 | x |
| 线性模型 | h_θ(x) = θ₀ + θ₁x |
| 参数 | θ₀, θ₁ |
| 代价函数 | J(θ₀, θ₁) = (1/m) Σ (h_θ(x⁽ⁱ⁾) − y⁽ⁱ⁾)² |
| 优化 | 选 θ₀, θ₁ 使 J 最小 |

### 讲师问："为什么用最小二乘（least squares）？"
课件没回答，常见理由有：
1. **可微（differentiable）**：平方函数光滑，可以求导 → 可以用梯度下降（对比绝对值 |误差| 在 0 处不可导）
2. **凸（convex）**：对线性模型来说 J 是碗形的，只有一个最小值，一定找得到
3. **数学上方便**：甚至有直接的公式解（normal equation，sklearn 就是这么算的）
4. **概率上有依据**：如果假设噪声是**高斯分布（正态分布）**，最小二乘等价于**最大似然估计（maximum likelihood）**——即找"最有可能产生这组数据"的参数
5. **重罚大误差**

**缺点**：因为平方会放大大误差，最小二乘**对离群点（outliers）很敏感**——一个特别离谱的点就能把整条线拽偏。

## 10. 梯度下降 Gradient Descent（Slide 11–12）

### 10.1 为什么需要它？
要找使 J 最小的 θ。最笨的办法是**暴力搜索（brute force）**：把所有 (θ₀, θ₁) 的组合都试一遍。参数一多（比如 Intro 里有几万个 θ），这完全不可行。

### 10.2 基本思路
```
从某个 θ₀, θ₁ 开始（随便猜一个）
重复：
    把 θ₀, θ₁ 更新成一个能让 J 更小的新值
```

> 💡 **下山比喻**：你被蒙着眼睛站在山坡上，想走到谷底。你看不到全局，但能用脚感受脚下哪个方向**最陡地往下**。于是每次往那个方向迈一小步，重复，最终就会走到谷底。
> - 山的地形 = J(θ) 曲面
> - 你的位置 = 当前的 θ
> - 感受坡度 = 计算**梯度（导数）**
> - 迈一步的大小 = **步长 α（learning rate）**

### 10.3 凸 vs 非凸
- **碗形 / 凸（convex）**：只有一个最低点，梯度下降**一定最终能找到最小值**（Slide 11）。线性回归就是这种情况 ✅
- **有多个低谷（非凸 non-convex）**（Slide 12）：
  - 从不同的起点出发，可能落到不同的谷底
  - 可能困在**局部最小值（local minimum）**，而不是**全局最小值（global minimum）**
  - 神经网络的 cost function 就是这种情况，以后会遇到

## 11. 导数 Derivatives（Slide 13–16）—— 梯度下降的数学基础

如果你微积分有点生疏，这一节要认真看。

### 11.1 直线（Slide 14）
y = mx + c
- **m 是斜率**：m > 0 往右上升，m < 0 往右下降，|m| 越大越陡
- **c 是截距**：x = 0 时 y 的值，整条线上下平移

### 11.2 一元函数的导数（Slide 13、15）
**f 在点 x′ 处的导数 = 在 x′ 处"刚好贴着"曲线的那条直线（切线 tangent line）的斜率。**

记号：df/dx (x′)，也常写成 f′(x′)。

推导切线方程：
- 切线斜率 m = df/dx (x′)
- 切线经过点 (x′, f(x′))，所以 c = f(x′) − m·x′
- 切线方程：y = df/dx (x′)·(x − x′) + f(x′)

**关键结论（一阶近似 / 线性近似）**：在 x′ 附近，

$$f(x) \approx f(x') + \frac{df}{dx}(x')\,(x - x')$$

意思是：**在一个点附近，任何光滑曲线都可以近似看成一条直线。** 离 x′ 越近，近似越准。

> 💡 这个近似告诉我们怎么让 f 变小：
> - 如果导数 > 0（曲线往右上升）→ 往左走（x 变小），f 就变小
> - 如果导数 < 0（曲线往右下降）→ 往右走，f 就变小
> - 统一写法：**往导数的反方向走**：x = x′ − α·f′(x′)
> 代入近似式：f(x) ≈ f(x′) − α·(f′(x′))² ≤ f(x′)，因为平方 ≥ 0，所以 f 一定变小（在 α 足够小时）。这就是梯度下降有效的原因！

### 11.3 多元函数：偏导数与梯度（Slide 16）
当输入有两个变量 x = [x₁, x₂]，函数 f(x₁, x₂) 是一个曲面，"贴着"它的不再是直线，而是一个**切平面**：

平面方程：y = m₁x₁ + m₂x₂ + c，有**两个斜率**：
- m₁ = **∂f/∂x₁**：**偏导数（partial derivative）**，只让 x₁ 变、x₂ 固定不动时 f 的变化率（沿 x₁ 方向的坡度）
- m₂ = **∂f/∂x₂**：同理，沿 x₂ 方向的坡度

> 💡 **偏导数怎么算？** 对 x₁ 求偏导时，**把其他变量都当成常数**，然后按普通求导来算。
> 例：f = x₁² + 3x₁x₂ → ∂f/∂x₁ = 2x₁ + 3x₂，∂f/∂x₂ = 3x₁

**梯度（gradient）** 就是把所有偏导数排成一个向量：

$$\nabla f(x') = \left[\frac{\partial f}{\partial x_1}(x'), \frac{\partial f}{\partial x_2}(x'), \ldots, \frac{\partial f}{\partial x_n}(x')\right]$$

∇ 读作 "nabla" 或 "del"。**梯度指向函数上升最快的方向**，所以**负梯度方向就是下降最快的方向**。

一阶近似同样成立：

$$f(x) \approx f(x') + \frac{\partial f}{\partial x_1}(x')(x_1 - x_1') + \frac{\partial f}{\partial x_2}(x')(x_2 - x_2')$$

如果选 x₁ = x′₁ − α·∂f/∂x₁，x₂ = x′₂ − α·∂f/∂x₂（每个变量都往自己偏导数的反方向走），代入得：

$$f(x) \approx f(x') - \alpha\left[\left(\frac{\partial f}{\partial x_1}\right)^2 + \left(\frac{\partial f}{\partial x_2}\right)^2\right] \lessapprox f(x')$$

所以函数值会下降。

> ⚠️ 课件 Slide 16 写的 "x₁ = x′ − α ∂f/∂x₁" 应该是 **x′₁**（第一个分量），x₂ 同理是 x′₂。

## 12. 线性回归的梯度下降算法（Slide 17）—— 核心公式

### 12.1 通用更新规则
```
重复：
    δ₀ := −α · ∂J/∂θ₀
    δ₁ := −α · ∂J/∂θ₁
    θ₀ := θ₀ + δ₀
    θ₁ := θ₁ + δ₁
```
- **α（alpha）** 叫**步长（step size）** 或**学习率（learning rate）**，要选得合适：不能太大也不能太小
- ":=" 表示"赋值/更新"（像编程里的 `=`）
- ⚠️ **注意顺序**：先用**旧的** θ₀、θ₁ 把 δ₀ 和 δ₁ **都算好**，然后再**同时**更新两个 θ。如果先更新了 θ₀ 再用新 θ₀ 去算 δ₁，就不是标准的梯度下降了。课件分成两步写就是为了强调这一点。

### 12.2 求出偏导数（推导过程，课件只给了结果）
J(θ₀, θ₁) = (1/m) Σ (θ₀ + θ₁x⁽ⁱ⁾ − y⁽ⁱ⁾)²

用**链式法则（chain rule）**：(u)² 的导数是 2u·(u 的导数)

- 对 θ₀：括号里 θ₀ + θ₁x − y 对 θ₀ 的导数是 **1**

$$\frac{\partial J}{\partial \theta_0} = \frac{2}{m}\sum_{i=1}^{m}\left(h_\theta(x^{(i)}) - y^{(i)}\right)$$

- 对 θ₁：括号里对 θ₁ 的导数是 **x⁽ⁱ⁾**

$$\frac{\partial J}{\partial \theta_1} = \frac{2}{m}\sum_{i=1}^{m}\left(h_\theta(x^{(i)}) - y^{(i)}\right)x^{(i)}$$

### 12.3 完整算法
```
重复：
    δ₀ := −(2α/m) · Σ (h_θ(x⁽ⁱ⁾) − y⁽ⁱ⁾)
    δ₁ := −(2α/m) · Σ (h_θ(x⁽ⁱ⁾) − y⁽ⁱ⁾) · x⁽ⁱ⁾
    θ₀ := θ₀ + δ₀
    θ₁ := θ₁ + δ₁
```

> 💡 **直观理解公式**：
> - 如果预测**普遍偏高**（h − y 大多 > 0），那么 δ₀ < 0 → θ₀ 变小 → 整条线往下移 ✅
> - 如果预测普遍偏低 → θ₀ 变大 → 线往上移 ✅
> - δ₁ 多乘了一个 x⁽ⁱ⁾：x 大的点对斜率的调整影响更大（因为改斜率对 x 大的点的预测影响也更大）

### 12.4 手算演示：用梯度下降解第 6 节的例子
第 6 节中 dJ/dθ₁ = 13θ₁ − 5，最优解 θ₁ = 5/13 ≈ 0.385。

**α = 0.05（合适的步长），从 θ₁ = 0 出发：**
| 迭代 | θ₁ | 梯度 13θ₁−5 | δ = −α×梯度 | 新 θ₁ | J |
|---|---|---|---|---|---|
| 0 | 0 | −5 | +0.25 | 0.25 | 1.0 → 0.156 |
| 1 | 0.25 | −1.75 | +0.0875 | 0.3375 | → 0.053 |
| 2 | 0.3375 | −0.6125 | +0.0306 | 0.3681 | → 0.040 |
| … | … | 越来越接近 0 | 越来越小 | → 0.385 | → 最小值 ≈ 0.038 |

注意：**越接近最低点，梯度越小，每一步自动变小**，平稳地收敛。

**α = 0.2（步长太大），从 θ₁ = 0 出发：**
| 迭代 | θ₁ | 梯度 | 新 θ₁ |
|---|---|---|---|
| 0 | 0 | −5 | 1.0 |
| 1 | 1.0 | +8 | −0.6 |
| 2 | −0.6 | −12.8 | 1.96 |
| 3 | 1.96 | … | 越跳越远 💥 |

在碗的两壁之间来回跳，而且越跳越高——**发散（diverge）**。这就是第 15 节说的 "overshooting"。
（对这个例子，可以算出 α 必须小于 2/13 ≈ 0.154 才会收敛。）

## 13. 实践：数据归一化 Normalising Data（Slide 18–19）

### 13.1 为什么要归一化？
使用梯度下降（其实一般也是）时，最好把输入和输出**缩放、平移**到大致 **0 到 1** 或 **−1 到 1** 的范围。
- 范围 1 → 100 还可以
- 问题在于范围**非常大**，比如 1 → 10⁶：
  1. **数值计算会出问题**（numerics）：数字太大容易溢出或精度丢失
  2. **数值大的数据会主导 cost function**，训练会只关注那部分数据

> 💡 **另一个直观理由**：如果一个特征范围 0–1000，另一个 0–1，J 的"碗"会被拉成一个**又细又长的山谷**。梯度下降在这种形状里会左右来回震荡，下降很慢；而且一个 α 对一个方向合适，对另一个方向可能太大。归一化后碗变圆，梯度下降能更直接地走向碗底。

### 13.2 两种常用方法
把 xⱼ 替换成 (xⱼ − μⱼ) / σⱼ：

**方法 1：标准化（Standardisation / z-score）**
- 平移 μⱼ = 特征 j 的**均值** = (1/m) Σ x⁽ⁱ⁾ⱼ → 让特征均值约为 0
- 缩放 σⱼ = 特征 j 的**标准差** = √[(1/m) Σ (x⁽ⁱ⁾ⱼ − μⱼ)²] → 让特征大部分落在 −1 到 1 之间

**方法 2：最小-最大缩放（Min-max scaling）**
- 平移 μⱼ = min(xⱼ)
- 缩放 σⱼ = max(xⱼ) − min(xⱼ)
- 结果正好落在 [0, 1]
- 例：TV 预算范围 0.7 到 296.4，变换 (TV − 0.7)/(296.4 − 0.7)，得到 0 ≤ x₁ ≤ 1

⚠️ **不要对 x₀ = 1 做归一化**（x₀ 在第 17 节解释，是为了截距 θ₀ 专门加的常数 1，归一化会把它变成 0/0）。

> ⚠️ 课件 μⱼ 公式里求和上限写成了 n，应该是 **m**（对所有样本求平均）。
>
> 💡 和 Intro 讲的 data leakage 联系起来：以后分训练/测试集时，**μ 和 σ 只能用训练集算**，然后用同样的 μ、σ 去变换测试集。
>
> 💡 归一化后学到的 θ 是针对**缩放后**特征的。解释系数或对新数据预测时，要记得用同样的方式变换输入。

## 14. 实践：什么时候停止？（Slide 20）

- **调试（debugging）**：怎么确认梯度下降在正常工作？→ **J(θ) 应该在每一次迭代后都下降**。画一张"J vs 迭代次数"的图，应该是一条单调下降、逐渐变平的曲线。
  - 如果 J 上升或上下跳 → 多半是 α 太大（或者梯度公式写错了）
- **停止条件（stopping criteria）**：以下两个条件**先满足哪个就停**：
  - J 的下降量小于某个阈值（例如 10⁻²）→ 说明已经接近最低点，再走也没多大改进
  - 达到固定的最大迭代次数（例如 200 次）→ 防止无限运行

## 15. 实践：选择步长 α（Slide 21）

| α | 后果 |
|---|---|
| **太小** | 每步都很小，收敛到最小值需要很长时间 |
| **太大** | 一步跨过最低点（**overshooting**），可能来回震荡甚至发散（见 12.4 的例子） |
| **合适** | 在合理时间内收敛 |

实践中常用的做法：先试 0.001, 0.01, 0.1, 1 这样按 10 倍变化的值，看 J 的下降曲线，选一个下降快又稳定的。

也有很多**自动调整 α** 的方法，例如 **line search（线搜索）**：每次迭代时试几个 α，直到找到一个确实能让 J 下降的值。

```python
import numpy as np

```

### 16.3 逐行解释
- `np.arange(0, 1, 0.01)`：生成 0, 0.01, 0.02, ..., 0.99，共 100 个数
- `.reshape(-1, 1)`：变成 **100 行 1 列**的二维数组。**sklearn 要求 X 必须是二维的**（行 = 样本，列 = 特征），哪怕只有一个特征。`-1` 表示"这一维自动推算"。这是新手最常遇到的报错原因之一。
- `np.random.normal(0.0, 1.0, 100)`：100 个均值 0、标准差 1 的**高斯随机噪声**
- 所以真实关系是 **y = 0 + 10x + 噪声**，即真实的 θ₀ = 0，θ₁ = 10
- `model.fit(X, y)`：训练，找最小二乘解
  - 注意 sklearn 的 `LinearRegression` **不是用梯度下降**，而是直接用线性代数公式一步算出精确解（最小二乘有公式解）
- `model.intercept_` = 学到的 **θ₀**，`model.coef_` = 学到的 **θ₁**（多特征时是数组）
- 典型输出 θ₀ ≈ 0.0175，θ₁ ≈ 9.77：和真实值 0、10 **很接近但不完全相等**——因为有噪声，而且只有 100 个样本。每次运行噪声不同，结果也会略有不同。

## 17. 多变量线性回归 Multiple Variables（Slide 25–28）

### 17.1 更多的特征
现在用全部三种广告预算来预测销量：

| TV | Radio | Newspaper | Sales |
|---|---|---|---|
| x₁ | x₂ | x₃ | y |
| 230.1 | 37.8 | 69.2 | 22.1 |

记号：
- **n = 特征数量**（这里 n = 3）。注意区分：**m = 样本数，n = 特征数**
- x⁽ⁱ⁾ 现在是一个**向量**：x⁽¹⁾ = [230.1, 37.8, 69.2]ᵀ
- **x⁽ⁱ⁾ⱼ = 第 i 个样本的第 j 个特征**，例如 x⁽¹⁾₂ = 37.8（第 1 个市场的 Radio 预算）

### 17.2 模型

$$h_\theta(x) = \theta_0 + \theta_1 x_1 + \theta_2 x_2 + \theta_3 x_3$$

例：Sales = 15 + 0.1×TV − 5×Radio + 10×Newspaper（这只是说明格式的例子，不是真正拟合的结果）

**每个 θⱼ 的含义**：在其他特征不变的情况下，特征 j 每增加 1，预测值变化多少。

### 17.3 x₀ = 1 的小技巧
为了写法统一，定义一个**永远等于 1 的"假特征" x₀ = 1**，然后：

$$x = \begin{bmatrix} x_0 \\ x_1 \\ \vdots \\ x_n \end{bmatrix}, \quad \theta = \begin{bmatrix} \theta_0 \\ \theta_1 \\ \vdots \\ \theta_n \end{bmatrix}$$

$$h_\theta(x) = \theta_0 x_0 + \theta_1 x_1 + \cdots + \theta_n x_n = \theta^T x$$

因为 x₀ = 1，所以 θ₀x₀ = θ₀，截距就自然地被包含进内积里了。这样 θ 和 x 都是 **n+1 维**向量。

> 💡 这就是 Intro 里的 θᵀx！Intro 的影评分类器和这里的线性回归，**模型形式完全一样**，区别只在于：分类最后取 sign(θᵀx) 得到类别，回归直接输出 θᵀx 这个数。

### 17.4 代价函数和优化（Slide 27）
和单变量完全一样，只是 θ 变成了向量：

$$J(\theta) = \frac{1}{m}\sum_{i=1}^{m}\left(h_\theta(x^{(i)}) - y^{(i)}\right)^2$$

梯度下降：
```
从某个 θ 开始
重复：
    for j = 0 到 n:  δⱼ := −α · ∂J/∂θⱼ
    for j = 0 到 n:  θⱼ := θⱼ + δⱼ
```
（还是先算完所有 δ，再一起更新所有 θ）

### 17.5 偏导数（Slide 28）

$$\frac{\partial J}{\partial \theta_j} = \frac{2}{m}\sum_{i=1}^{m}\left(h_\theta(x^{(i)}) - y^{(i)}\right)x_j^{(i)}$$

- 推导和 12.2 一样：θ₀x₀ + θ₁x₁ + … 对 θⱼ 求偏导，只剩下 xⱼ
- j = 0 时，x₀⁽ⁱ⁾ = 1，就退化成了 12.2 里 θ₀ 的公式——**x₀ = 1 这个技巧让所有参数共用一个公式**

完整算法：
```
重复：
    for j = 0 到 n:  δⱼ := −(2α/m) · Σᵢ (h_θ(x⁽ⁱ⁾) − y⁽ⁱ⁾) · x⁽ⁱ⁾ⱼ
    for j = 0 到 n:  θⱼ := θⱼ + δⱼ
```

> ⚠️ 课件 Slide 28 的 J(θ) 前面漏了 1/m，但偏导数里有 2/m，以 Slide 27 的定义（带 1/m）为准。
>
> 💡 **向量化写法**（以后写代码会用到）：把所有样本排成矩阵 X（m 行 × (n+1) 列，第一列全是 1），则所有预测是 Xθ，梯度是 (2/m)·Xᵀ(Xθ − y)。用 numpy 一行就能算完所有 j，不需要 for 循环，而且快得多。

## 18. 广告数据：进一步的思考（Slide 29）

Slide 29 画了用 TV 和 Radio 两个特征拟合的 3D 图（两个特征 → 拟合的是一个**平面**而不是直线）。讲师提出两个问题：

### 18.1 "TV 和 Radio 广告的效果之间有什么关系？"
- 在 ISLR 教材的分析中，数据显示出**协同效应（synergy / interaction effect）**：同时投 TV 和 Radio，效果比各自单独投放加起来还要好。
- 普通线性模型 θ₀ + θ₁·TV + θ₂·Radio 假设两者效果**独立相加**，无法表达这种协同效应。于是残差会有规律：两种都投得多或者只投一种的市场，预测会偏；两者比较均衡的市场，真实销量高于平面预测。

### 18.2 "二次拟合会不会更好？对预算分配意味着什么？"
- 可以加入新的特征，比如 **TV × Radio**（交互项）、**TV²**（平方项）：
  h(x) = θ₀ + θ₁·TV + θ₂·Radio + θ₃·TV×Radio + ...
- ⚠️ 重要概念：**这仍然是"线性回归"！** 因为模型对**参数 θ 是线性的**。"线性"指的是 θ 的线性组合，特征本身可以是 x 的任何非线性函数。所以前面所有的 cost function、梯度下降公式全部照用，只是多了几个特征。
  → 这就是 **Week 2 Feature Engineering（特征工程）** 要讲的内容
- 对预算的意义：如果交互项 θ₃ > 0，说明**把预算分散到 TV 和 Radio 两者上**比全部砸在其中一个上更划算。

> 💡 这就是机器学习对"business application"（Intro 里说"真正重要的"）的意义：模型不仅用来预测，还能帮助做决策。

## 19. 本讲知识结构总结

```
回归问题：预测连续数值
    │
    ├─ 模型：h_θ(x) = θᵀx（x₀ = 1 包含截距）
    │
    ├─ 代价函数：J(θ) = (1/m) Σ (h_θ(x⁽ⁱ⁾) − y⁽ⁱ⁾)²   ← 最小二乘 / MSE
    │     └─ 线性回归的 J 是凸的（碗形）→ 只有一个最小值
    │
    ├─ 优化：梯度下降
    │     ├─ 导数 = 切线斜率；梯度 = 偏导数组成的向量，指向上升最快方向
    │     ├─ 更新：θⱼ := θⱼ − α · (2/m) Σ (h_θ(x⁽ⁱ⁾) − y⁽ⁱ⁾) x⁽ⁱ⁾ⱼ （所有 j 同时更新）
    │     └─ 实践：归一化数据 / 检查 J 每步都下降 / 设置停止条件 / 选合适的 α
    │
    ├─ 评估：看残差是否随机
    │
    └─ 扩展：加交互项、平方项 → 仍是线性回归 → 特征工程（Week 2）
```

3. 直接相加，正负误差会抵消（总误差可能为 0 但每个点都错得离谱）。平方使所有误差为正、可导、凸，并且重罚大误差。
