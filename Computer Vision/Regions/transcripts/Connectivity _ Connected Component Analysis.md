## Regions vs edges

So segmentation forms two sort of main techniques within vision. One of them is based on regions, and the other is based on edges. So regions are areas, if you like, or pixels which are beside each other and can group together into specific regions within an image. Edges are the boundaries between regions. So you can think of regions basically as consistent colour areas within an image. And the edges are the delineations between those regions. When we're looking at segmentation, we look at it in those two different ways. And so we have techniques that look at the regions themselves and look to get some sort of continuity or self-similarity within those regions, so homogeneity, if you like, within the regions. And then we look at other techniques which try and find the boundaries, so the places where the image changes. And those two techniques typically are quite distinct.

## Segmenting into objects

So the purpose then of segmentation is to split an image into smaller parts. And originally we tried to have segmentation where we were segmenting into objects. In reality we can't segment into objects directly because we'd need to know what the objects are. So if you consider a person, for example, and they're wearing a t-shirt and a pair of trousers, without knowing that they're a person, you can't say that the t-shirt and the pair of trousers have anything to do with each other, okay, assuming they're a different colour. And so if you were just analysing a static image of a person, you might think that that t-shirt and that pair of trousers were different objects. Interestingly, you could actually claim that they are different objects because they're different pieces of clothing. But if I'm wearing a plaid shirt, I have the same problem. How do I know that these different colours that are on my shirt in some way belong together? Okay, so how do we segment something into objects? And that is a much, much more complex problem than people originally realised. And so we now try and segment into regions which have some sort of homogeneity, some sort of self-similarity.

So we've talked about the notion that there's two approaches here, that one is looking at finding areas which are self-similar, and the other is looking at finding boundaries effectively between those areas. So there's some relationship between these two things. And in theory, they could work together.

## The connectivity problem

Okay, so before we get into the segmentation techniques, we actually have to look at a slight problem we have in the image domain. And this will seem like a trivialization, if you like, of a problem. It doesn't seem like it should be any sort of big deal. But let's go through it anyway. Okay, so there's a problem in an image. So if you have a two-dimensional array like this, you have to decide which pixels are connected to which other pixels.

So if we look at this image, and we look at the dark areas, effectively the circles that are in this image, let's look at the outer circle, we would see this as a reasonably continuous circle. The problem is that we can also consider the background as being connected. So if you look at this point of the image here, the connection between these two points in the background, these two white points, looks as strong as the connection as we go around the circle. So which of these regions is connected? It can't be both. From a logical point of view, it cannot be both. And we need to be able to come up with a single interpretation of a scene. We can only say that there's a background region here, and there's another region inside the circle. So somehow we have to come up with some way of dealing with this.

## 4-adjacency and 8-adjacency

The initial suggestions which are made within vision were to use two types of connectivity, four adjacency and eight adjacency. So in four adjacency, this center pixel number eight is connected to pixels zero, two, four, and six, and is not connected to pixels one, three, five, and seven. The alternative to this is to use eight adjacency. And in eight adjacency, the center pixel is connected to all eight of its neighbors.

Now, if we take the image we saw on the previous slide, and we apply four adjacency and eight adjacency to this, in the four adjacency case, sorry, I got missed the wrong way around. In the four adjacency case, we will get this type of segmentation here. So all the white points are connected together. All of these pink points are connected together. But then when we look at all the other regions, these light blue points are connected together, but they're not connected to this green point, and that's not connected to these gray points, and so on. So we have a lot more regions here than we would like. Okay, so we have a significant number of distinct regions.

In the other situation, the one where we use eight adjacency, here we have the circle is connected as a green region, and this other circle is connected as a red region. And the background is all connected. So this is the problem that we're trying to deal with.

We don't want this type of connectivity, because there's too many regions, and it will make it too hard to analyze. We can't see the fact that there's a circle here at all when we have it split up into so many regions. But at the same time, we have a paradox if we're using eight connectivity.

## The solution: alternating connectivity

So the solution that's proposed in vision is a reasonably practical one, but it is arbitrary. And the solution is that what we do is we use these two connectivity techniques alternately. So first of all, we assume that we have the background on the outside. I should note that all of this only applies to binary images. So it's images where we have object pixels, and we have background pixels. So we tend to refer to these objects and background. So any two distinct levels.

On the very outside level, we assume we have background. And we use four connectivity or four adjacency within the background. Any objects that are within that background region are treated with eight adjacency. And so therefore we get a continuous black region here. Any holes that appear within any objects that have appeared within the background are treated using four adjacency. So on the outside background, we're using four adjacency. On any objects that appear within that, we're using eight adjacency. With any holes that appear within the objects, we're using four adjacency. And then any objects that appear within the holes, we're using eight adjacency. And we keep doing that alternately.

It is arbitrary. And there are occasions where we will be making the wrong decisions, the wrong connections. But within vision, within computer vision, we tend to have this drive to have a single interpretation of a scene. We don't want there to be multiple interpretations that we consider simultaneously.
