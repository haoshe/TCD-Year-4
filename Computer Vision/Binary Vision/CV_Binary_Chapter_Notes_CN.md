# 计算机视觉 — 章节：二值视觉（Binary Vision）
*笔记整理自课程幻灯片 + 讲课文字稿（Binary、Cleaning Binary Images）*

---

## 0. 什么是二值视觉？为什么要学它？

**二值图像处理（Binary image processing）** = 把一幅图像（通常是灰度图）转换成**黑白图像**，使每个像素都被标记为以下之一：
- **1 — 感兴趣的目标**（前景），或
- **0 — 不感兴趣的部分**（背景）。

课上的例子：
- **车牌：** 裁剪出车牌 → 转为灰度 → 转为二值。字符变成黑色、车牌底色变成白色，于是每个黑色区域都是一个候选字符。把每个字符的像素归为一个"区域"属于区域处理（region processing），课程后面会讲。
- **交通标志：** 先把每个像素标记为"红色 / 非红色"。然后*在*红色区域*内部*，再把像素标记为"黑色 / 非黑色"。两者结合就能提取出标志的内容。

**什么时候有效？** 只在**受约束（constrained）**的场景下有效，即感兴趣的目标能可靠地与背景分离。注意这两个例子都是人造物体（标志、车牌），尽管它们是在真实世界中拍摄的。

**为什么它在历史上如此重要：** 早期的很多视觉系统（尤其是**工业**视觉）完全基于二值图像，因为它**非常快**：没有颜色，每个判断都只是简单的是/否。这在老旧硬件上非常关键。如今我们受到的限制少了很多，但这些思想仍作为基础构件被广泛使用。

> **贯穿整章要记住的核心思想：** 二值视觉几乎丢弃了图像中的所有信息，每个像素只保留一个是/否。当前景与背景的区分*确实*是一个是/否问题时，这非常好用；当不是时，效果就很糟糕。

本章结构：
1. **阈值化（Thresholding）**：灰度 → 二值
2. **阈值检测（Threshold detection）**：自动选择阈值（Otsu 大津法）
3. **变体**：自适应阈值化、多光谱阈值化
4. **二值图像清理**：数学形态学（腐蚀、膨胀、开运算、闭运算），以及灰度/彩色形态学和寻找局部极大值

## 1. 阈值化（Thresholding）

### 1.1 二值阈值化
对每个像素，将其灰度值 $f(i,j)$ 与阈值 $T$ 比较：

$$
g(i,j) = \begin{cases} 1 & \text{if } f(i,j) \geq T \\ 0 & \text{if } f(i,j) < T \end{cases}
$$

- $f(i,j)$ 是输入的灰度图像，$g(i,j)$ 是输出的二值图像。
- 实际中"1"通常存储为 **255**，这样显示时二值图像才看得见（像素值 1（满值为 255）看起来就是黑色）。
- 哪一侧算作"目标"取决于场景。对于浅色车牌上的深色文字，目标是*低于阈值*的部分。OpenCV 为此提供了反转模式（`THRESH_BINARY_INV`）。

⚠️ **只适用于简单场景**：前景和背景在灰度上必须**明显不同**。讲师反复强调这一点：使用阈值化*之前*，先确认它是否适用。

### 1.2 查找表（LUT, Look-Up Table）：一个加速技巧
与其对每个像素做一次比较，不如对每个*可能的*灰度级预先计算一次结果：

$$
\text{LUT}(k) = \begin{cases} 1 & k \geq T \\ 0 & k < T \end{cases} \quad \text{for } k = 0 \ldots 255
$$

然后对每个像素，$g(i,j) = \text{LUT}(f(i,j))$。

> **为什么有用：** LUT 只有 256 个条目，而一幅图像可能有数百万个像素。现在每个像素只需要一次数组查找，而不是一次比较加分支。这在早期视觉中非常重要。如今它没那么重要了，效率方面的关注点已转向视频、超大图像以及多尺度（金字塔）处理等。

### 1.3 OpenCV
```cpp
threshold(gray_image, binary_image, threshold, 255, THRESH_BINARY);
```
- 输入必须是**单通道**（灰度）图像。
- `threshold` 就是 $T$；`255` 是 **≥ T** 的像素的输出值（实际上 OpenCV 用的是严格的 **> T**，这个细节很少有影响）。
- `THRESH_BINARY` 选择操作类型。还有其他模式（反转、截断、置零……）。

### 1.4 为什么选择 T 很难
课程视频在一幅 **PCB（印刷电路板）** 图像上逐步调整阈值：
- **T 太低** → "亮"的像素太多，相邻的走线（track）会粘连在一起。
- **T 太高** → 像素太少，走线断开（出现虚假的连通性缺口）。
- 非常高 → 几乎什么都不剩。

在困难的图像上，可能**不存在一个完美的 T**。这引出了下一个问题：我们如何选择 T？

## 2. 阈值检测（Threshold Detection）

### 2.1 手动设置（以及它为什么会失败）
你可以拖动滑块直到结果看起来不错。问题在于，在真实系统中**光照会变化**：
- 一天中不同的时间、不同的环境。
- 即使在光照受控的密封工业检测箱里，**灯泡也会随时间老化**，所以固定阈值会慢慢偏离，系统最终会失效。

➡️ 我们需要为每幅图像**自动**确定 T。

### 2.2 直方图：解决这个问题的工具
后续方法使用的记号：
- **图像：** $f(i,j)$
- **直方图：** $h(g)$ = 灰度值为 $g$ 的像素数量，$g = 0 \ldots 255$
- **归一化概率分布：**
$$ p(g) = \frac{h(g)}{\sum_g h(g)} $$
即把每个计数除以总像素数，使所有值之和为 1。$p(g)$ 表示"图像中灰度值为 $g$ 的像素所占的比例"。

> **直觉理解：** 如果图像是浅色背景上的深色物体，直方图通常有**两个峰**（即*双峰*，bimodal）：一个对应物体像素，一个对应背景。好的阈值位于**两峰之间的谷底**。Otsu 方法就是一种有理论依据的寻找这个谷底的方法。

### 2.3 Otsu 阈值法（OpenCV 使用的方法）
**目标：** 把像素分成两类，**前景（F）** 和 **背景（B）**，使每一类都尽可能**紧凑（离散程度低）**。

阈值 $T$ 下的**类内方差（within-class variance）**：
$$ \sigma_W^2(T) = w_f(T)\,\sigma_f^2(T) + w_b(T)\,\sigma_b^2(T) $$

- **权重**表示每一类像素所占的比例：
$$ w_f(T) = \sum_{g=T}^{255} p(g) \qquad w_b(T) = \sum_{g=0}^{T-1} p(g) $$
- **类均值**表示每一类的平均灰度值：
$$ \mu_f(T) = \frac{\sum_{g=T}^{255} g\,p(g)}{w_f(T)} \qquad \mu_b(T) = \frac{\sum_{g=0}^{T-1} g\,p(g)}{w_b(T)} $$
- **类方差**表示每一类围绕其自身均值的离散程度：
$$ \sigma_f^2(T) = \frac{\sum_{g=T}^{255} (g-\mu_f)^2\,p(g)}{w_f(T)} \qquad \sigma_b^2(T) = \frac{\sum_{g=0}^{T-1} (g-\mu_b)^2\,p(g)}{w_b(T)} $$

*（PDF 中的公式幻灯片是一张图片，所以这里写的是标准的 Otsu 定义，与讲师的描述一致。请对照第 6 张幻灯片核对。）*

**算法：**
1. 计算直方图和 $p(g)$，**只需一次**。
2. 对**每一个**可能的 $T$（只有 256 个），计算 $\sigma_W^2(T)$。
3. 选取**类内方差最小**的 $T$。

这非常快：你无需再回到图像本身，只需在直方图上做 256 次简单计算。

**类间方差（实现上的技巧）：**
最小化类内方差**等价于**最大化**类间方差（between-class variance）**：
$$ \sigma_B^2(T) = w_f(T)\,w_b(T)\,\big(\mu_f(T) - \mu_b(T)\big)^2 $$
这个版本计算更便宜，因为不需要计算每一类的方差求和，所以实现中通常改为最大化它。

> **为什么二者等价？** 图像的总方差 = 类内方差 + 类间方差，而总方差与 $T$ 无关。所以一个变小，另一个必然变大。直观上，你希望每一类都紧凑（类内小），同时两类的均值相距很远（类间大）。

> **理解小贴士：** 讲师承认这些数学"需要坐下来慢慢琢磨"。画一个直方图，选一个 T，把左边（背景）和右边（前景）涂上阴影，然后问：每一侧的权重（面积）、均值（中心）和离散程度分别是多少？这些公式算的就是这些东西。

**OpenCV：** 加上 `THRESH_OTSU` 标志。此时传入的 `threshold` 参数会被**忽略**，由 Otsu 来选择阈值（函数返回所选的值）。
```cpp
threshold(gray_image, binary_image, threshold, 255, THRESH_BINARY | THRESH_OTSU);
```

在 PCB 图像上，Otsu 给出了非常干净的结果。剩下的瑕疵主要来自**光照不佳**。在工业视觉中，**把光照做好**往往能让图像处理简单得多。

## 3. 阈值化的变体

### 3.1 自适应阈值化：动机
当整幅图像的光照不均匀时，**单一的全局阈值**会失效。例子：一张扫描的公寓平面图，**右下角暗、左上角亮**。任何一个 T 都会把其中一侧抹掉。

第二个例子，一个**火车站**（转为灰度）：全局 Otsu 丢失了黄色标牌和站台上的大号"2"标志。

➡️ 思路：**在图像的不同区域使用不同的阈值**。

### 3.2 经典自适应阈值化（子图像 + 插值）
1. 把图像**划分**成若干子图像（课上用的是 **8 × 8 = 64** 块）。
2. **为每个子图像计算一个阈值**，例如对该块的直方图使用 Otsu。
3. 使用**双线性插值（bilinear interpolation）**为每个像素**插值**出阈值，依据是该像素到相邻各块中心的距离。这样阈值会平滑变化，而不会在块边界处突变。

> **什么是双线性插值？** 对于位于四个块中心之间的像素，取这四个阈值的加权平均，离得越近的中心权重越大。先在水平方向插值，再在竖直方向插值（因此叫"双-线性"）。

**失效情况：** **基本均匀**的块（例如平面图顶部的空白纸）。Otsu *总会*返回某个阈值，即使该块中根本没有可分离的东西，于是它最终会去分割噪声或平缓的渐变，产生垃圾结果。**检测提示：** 这样的块的阈值会与其相邻块的阈值差别很大。

### 3.3 OpenCV 的自适应阈值化（局部均值）
OpenCV 的版本工作方式不同：它把**每个像素与其自身邻域的均值**进行比较：

$$
g(i,j) = \begin{cases} 255 & \text{if } \left( f(i,j) - \dfrac{\sum_{a=-m}^{m}\sum_{b=-m}^{m} f(i+a,\,j+b)}{(2m+1)^2} \right) > \text{offset} \\[8pt] 0 & \text{otherwise} \end{cases}
$$

- 邻域是以该像素为中心的 $(2m+1)\times(2m+1)$ 正方形。课上 $m = 40$，即 **81 × 81** 的块。
- **偏移量（offset）**（课上为 5）用于避免对**噪声**产生反应。在平坦区域，每个像素都大致等于其局部均值，所以如果与 0 比较，像素会随着微小的噪声波动而随机翻转。
- 用文字表述：如果一个像素明显比其周围更亮，它就是前景。

```cpp
adaptiveThreshold(gray_image, binary_image, output_value,
                  ADAPTIVE_THRESH_MEAN_C, THRESH_BINARY,
                  block_size, offset);   // 课上：block_size = 81, offset = 5
```
> ⚠️ 符号约定：OpenCV 实际的公式是 `f(i,j) > mean − C`，即从均值中*减去*偏移量。所以你传入的偏移量的符号与幻灯片上的公式是相反的。在实验课中使用时值得查一下文档。

**在火车站图像上的结果：** 好多了。"2"很清晰，黄色标牌上的文字也开始显现。但同样的弱点依然存在：一块**颜色恒定的区域**（"2"的左侧）变成了一整块白色，因为那里没有真正可供阈值化的结构。

**调参：** 块大小必须与你要寻找的东西的尺度相匹配。太小则无法"看到"物体周围的背景；太大则表现得像全局阈值。

### 3.4 多光谱 / 多级阈值化
使用**多个阈值**把图像分成**两类以上**。例子来自一幅 MRI 脑部扫描（北卡罗来纳大学，已发表的研究）：利用在灰度直方图中找到的阈值，分离出**白质、灰质和皮层下结构**，然后分别以红/绿/蓝显示。

**讲师的批评（重要！）：** 直方图中三个类别的分布**有大量重叠**。重叠尾部的每一个像素都会被**错误分类**，而这样的像素很多。讲师认为临床决策可能依赖于此，这令人担忧。

> **教训：** 这又回到了本章的黄金法则。**只有当各类别在你所阈值化的特征上确实明显不同时，才使用阈值化。** 如果直方图重叠，没有任何阈值能把它们分开，就需要更强大的技术。

## 4. 二值图像清理：数学形态学

### 4.1 为什么需要专门的清理操作
直接由阈值化得到的二值图像很少是干净的：
- **孤立噪声点**：周围什么都没有的单个"亮"像素。
- **粗糙、锯齿状的区域边界**，这会让后续的形状分析变得困难。
- 物体内部的**孔洞**，以及本应相连的物体中出现的**断裂**。

我们**不能使用常规的平滑方法**（"图像"一章中的均值、高斯等）。对 0 和 255 求平均会得到像 113 这样的值，那么图像就不再是二值的了。取而代之，我们从**形状**的角度来思考。

**数学形态学（Mathematical morphology）** 把二值图像看作前景像素坐标的一个**集合**，并在这些集合上定义操作。它本身就是一个很大的领域。本课程只涵盖四种最常用的操作：**膨胀、腐蚀、开运算、闭运算**。

### 4.2 结构元素（Structuring element）
**结构元素** $B$ 是一个小形状（通常是 **3×3** 正方形），带有一个指定的**原点**，通常是其中心。它定义了我们在处理每个像素时"哪些邻居算数"。可以把它看作滤波核在二值情形下的对应物。

- **各向同性（isotropic）** 结构元素：一个实心、"连续"、没有空隙的形状，比如完整的 3×3 或 5×5 正方形（或圆盘）。它在各个方向上的表现大致相同。
- 更大的元素（5×5、7×7……）效果更强（更多平滑、填充更大的孔洞、去除更大的噪声）。

### 4.3 膨胀（Dilation, ⊕）：使区域变大
**闵可夫斯基集合加法（Minkowski set addition）：**
$$ X \oplus B = \{\, p \in \mathbb{Z}^2 \;:\; p = x + b,\; x \in X,\; b \in B \,\} $$

- $X$ = 原始图像中前景像素的集合，$x$ = 其中一个像素，$B$ = 结构元素。
- **用文字表述：** 在每个前景像素上放一个 $B$ 的副本。被任意副本覆盖到的像素在输出中都是前景。
- 使用 3×3 的 $B$ 时，每个单独的像素都变成一个 3×3 的团块，所以每个区域的边界**向外扩张一个像素**。

**效果：**
- 让区域**变大**。
- **填充小孔洞。**
- **连接相近的区域**（弥合小缺口）。

**PCB 应用：** 对走线做膨胀。如果膨胀后两条走线几乎碰到一起，说明它们布得**太近了**，存在潜在的短路风险。膨胀也可以重新连接被阈值化意外断开的区域。

### 4.4 腐蚀（Erosion, ⊖）：使区域缩小
**闵可夫斯基集合减法（Minkowski set subtraction）：**
$$ X \ominus B = \{\, p \in \mathbb{Z}^2 \;:\; p + b \in X \;\text{ for every } b \in B \,\} $$

- **用文字表述：** 把 $B$ 放在像素 $p$ 上。**只有当 $B$ 覆盖下的每个像素都是前景时**，像素 $p$ 才会保留。如果（按照 $B$）有任何一个邻居是背景，$p$ 就会被去掉。
- 其效果是边界像素被剥离。讲师指出这是*效果*，而正式定义是"$B$ 是否完全落在物体内部？"这一检验。

**效果：**
- 让区域**变小**。
- **去除噪声**：孤立点和小团块会完全消失。
- **去除细窄的桥接**：两个区域之间的细连接会被切断。

**PCB 应用：** 对走线做腐蚀。如果某条走线**断开**了，说明它在那一点太细，可能无法正常传导信号，这标志着一个制造缺陷。

> ⚠️ **腐蚀和膨胀并不互为逆运算。** 如果腐蚀把一个小特征完全删掉了（比如幻灯片例子中的那个小 L 形），膨胀就没有东西可以用来恢复。信息丢失了。

> **值得记住的对偶性：** 对前景做腐蚀等同于对背景做膨胀（反之亦然）。

### 4.5 开运算（Opening, ∘）：先腐蚀再膨胀
$$ X \circ D = (X \ominus D) \oplus D $$

**动机：** 腐蚀能清理图像但会让物体缩小。之后再做膨胀可以恢复大小。
- **去除噪声**并**去除细窄的桥接**（腐蚀的好处，膨胀无法撤销，因为那些部分已经没了）。
- **大致保持区域大小。**
- **平滑形状**：尖锐的突起和锯齿状的外边缘会被修剪掉。

记忆方法：开运算**打开缺口**，断开细连接并删除小斑点。

### 4.6 闭运算（Closing, •）：先膨胀再腐蚀
$$ X \bullet D = (X \oplus D) \ominus D $$

- **填充小孔洞**并**连接相近的区域**（膨胀的好处）。一旦孔洞或缺口被填上，随后的腐蚀不会再把它重新打开。
- **大致保持区域大小。**

记忆方法：闭运算**闭合孔洞和缺口**。

> **快速对比：**
>
> | 操作 | 顺序 | 去除 | 填充 / 连接 | 大小 |
> |---|---|---|---|---|
> | 膨胀 | ⊕ | — | 孔洞、缺口 | 变大 |
> | 腐蚀 | ⊖ | 噪声、桥接 | — | 变小 |
> | 开运算 | 先 ⊖ 后 ⊕ | 噪声、桥接 | — | ≈ 保持 |
> | 闭运算 | 先 ⊕ 后 ⊖ | — | 孔洞、缺口 | ≈ 保持 |

### 4.7 性质
- 各向同性结构元素会**消除图像中的小细节**（任何比该元素小的东西）。
- **幂等性（Idempotence）：** 用*同一个*结构元素再做一次开运算（或闭运算），结果不变：
$$ X \circ D = (X \circ D) \circ D \qquad X \bullet D = (X \bullet D) \bullet D $$
  这对单纯的腐蚀或膨胀**不**成立（每重复一次都会继续缩小或变大）。如果第二次使用不同大小的结构元素，它也不成立。

### 4.8 应用实例：离开图书馆的人
一个综合运用前面所有内容的实际流程：
1. 建立**背景模型**：场景中没有人时的样子（从视频中得到）。
2. 从当前帧中**减去**背景，得到**差分图像**。
3. 对差分图像做**阈值化**，得到一幅"发生变化的东西"的二值图像。
4. 原始二值图很乱：当人的衣服与背景相似时，人体上会出现孔洞和断裂（裤腿与楼梯扶手是同样的灰色，一个人经过色调相近的展示柜）。
5. **闭运算**填补这些断裂。看起来有点方块化，但人变成了实心的。
6. **开运算**去除剩余的噪声，例如一扇**正在缓慢关闭的门**产生的细竖条纹。
7. 结果是两个干净的、大小大致正确的人形团块。随后可以用形状分析（高而窄）来确认它们是人。

同样的"先闭后开"方法也可用于发现 **PCB 走线中的断裂**。

> **要点：** 实践中你会把这些操作**串联**起来，根据图像中"乱"的类型来选择顺序和结构元素的大小。

### 4.9 OpenCV 代码
```cpp
// 使用默认的 3x3 各向同性结构元素进行膨胀（传入一个空 Mat）
dilate(binary_image, dilated_image, Mat());

// 使用显式的 5x5 各向同性结构元素（全为 1）进行膨胀
Mat structuring_element(5, 5, CV_8U, Scalar(1));
dilate(binary_image, dilated_image, structuring_element);

// 腐蚀：用法完全相同，只是调用 erode
erode(binary_image, eroded_image, Mat());
erode(binary_image, eroded_image, structuring_element);

// 开运算和闭运算
Mat five_by_five_element(5, 5, CV_8U, Scalar(1));
morphologyEx(binary_image, opened_image, MORPH_OPEN,  five_by_five_element);
morphologyEx(binary_image, closed_image, MORPH_CLOSE, five_by_five_element);
```
*（`getStructuringElement(MORPH_ELLIPSE, Size(5,5))` 是生成非正方形形状（如圆盘）的便捷方法。）*

## 5. 二值之外的形态学

### 5.1 灰度与彩色形态学
形态学并不只适用于二值图像。要把它推广到灰度图：
- 对**每一个灰度级 $g$**，构造一个集合，包含**所有值 ≥ $g$ 的像素**。所以值为 255 的像素属于每一个集合，而值为 3 的像素只属于 1、2、3 对应的集合。
- 对**每个集合分别**做腐蚀/膨胀，然后重新组合成图像。

> **实用捷径（结果等价）：** 灰度**膨胀 = 结构元素范围内的局部最大值**，灰度**腐蚀 = 局部最小值**。实际计算时就是这么做的，而且这样理解起来也容易得多。

- **彩色：** 对**每个通道的每个灰度级**做同样的处理，例如一幅 RGB 图像有 255 × 3 个集合。
- **效果：** 膨胀让亮区向外扩散，腐蚀让暗区向外扩散。它能产生有趣的"绘画感"效果，并可以让后续处理更容易。讲师认为它没有得到充分利用。

### 5.2 寻找局部极大值（后面会非常有用！）
在识别任务中，我们经常**在每个像素处计算一个"匹配程度"**（这里周围的图像与我要找的东西有多匹配？）。然后我们想找出**峰值**：即局部极大值。

**形态学方法：**
1. 对图像做**膨胀**。每个像素变为其邻域的最大值。
2. 把膨胀后的图像与原图**比较**。两者**相等**的地方，说明该像素*原本*就是其邻域的最大值，因此是局部极大值。
3. 对原图做**阈值化**，只保留足够高、值得关注的点。
4. 对两个结果做**逻辑与（AND）**，只得到**"高"的局部极大值**。低于阈值的小凸起会被排除。

（局部极小值的做法相同，改用腐蚀即可。）

```cpp
Mat dilated, thresholded_input, local_maxima, thresholded_8bit;
dilate(input, dilated, Mat());
compare(input, dilated, local_maxima, CMP_EQ);                        // 相等 => 局部极大值
threshold(input, thresholded_input, threshold, 255, THRESH_BINARY);  // 是否足够高？
thresholded_input.convertTo(thresholded_8bit, CV_8U);                // 统一类型以便做 AND
bitwise_and(local_maxima, thresholded_8bit, local_maxima);            // 同时满足两个条件
```

> **为什么这很重要：** 这适用于*任何*二维（或 n 维）数值数组，而不仅仅是照片：匹配得分、热力图、累加器数组。在特征检测和模板匹配中你很可能会再次见到它。

## 快速回顾：需要记住的要点
- **阈值化**把灰度图转为二值图：若 $f \geq T$ 则 $g = 1$。它快速而简单，但**只有在前景和背景确实明显不同时才有效**。LUT 可以让它更快。
- **手动阈值会随光照变化而失效**，所以要从**直方图**中自动检测 T。
- **Otsu**：尝试全部 256 个阈值，选取**类内方差最小**的那个，等价于**类间方差最大**。在 OpenCV 中就是 `THRESH_OTSU`。
- **自适应阈值化**用于处理光照不均：
  - 经典方法：每块做 Otsu，再做双线性插值。
  - OpenCV：把每个像素与其局部均值减去偏移量进行比较（`adaptiveThreshold`，例如块大小 81，偏移量 5）。
  - 两者在**均匀区域**都会失效。
- 类别直方图相互重叠的**多级阈值化**必然导致误分类（MRI 例子）。
- 二值图像不能用常规方式平滑，所以要用**形态学**：
  - **膨胀**使区域变大、填充孔洞、连接区域。
  - **腐蚀**使区域缩小、去除噪声、切断桥接。
  - 二者**不是互逆的**。
  - **开运算**（先腐蚀→后膨胀）去除噪声和桥接，同时保持大小。
  - **闭运算**（先膨胀→后腐蚀）填充孔洞和缺口，同时保持大小。
  - 开运算和闭运算都具有**幂等性**。
- 形态学可以推广到**灰度/彩色**图像（膨胀 = 局部最大值，腐蚀 = 局部最小值），并提供了一种寻找**局部极大值**的简洁方法（膨胀、比较相等、阈值化、AND）。
