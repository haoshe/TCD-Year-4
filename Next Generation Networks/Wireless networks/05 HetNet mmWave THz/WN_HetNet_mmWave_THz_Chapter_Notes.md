## 5.1 如何提升容量？三条路

1. **Radio link efficiency（链路效率）**：同一条链路上传更多 bps（更好的调制编码、MIMO…）
2. **Spectrum（频谱）**：拿到更多频谱（→ mmWave、THz）
3. **Topology（拓扑）**：在无线基础设施中部署更多节点（→ 小区加密、HetNet）

> 💡 对照香农公式：$C = \underbrace{m}_{\text{链路效率}} \cdot \underbrace{B}_{\text{频谱}} \cdot \log_2(1+\text{SINR})$，再乘以**单位面积内的小区数**（拓扑）——对应三条路。

## 5.2 小区加密 (Cell densification)

标准蜂窝网 → 密集网络 (Dense) → **超密集网络 (UDN, Ultra-Dense Networks)**

⚠️ **UDN 的定义：基站 (BS) 数量比用户 (UE) 还多。**（课件例题答案）

**HomNet vs HetNet**
- **同构网络 (Homogeneous)**：只有宏基站 (macro-cell BS)。
- **异构网络 (Heterogeneous)**：宏基站 + 大量**小基站**（pico/femto，也叫 **LPN, Low Power Node**）。

**HetNet 的好处**：改善小区边缘用户的覆盖；提高吞吐量。

## 5.3 "更多节点 = 更高吞吐量？" —— 不一定！

- **Area Spectral Efficiency (ASE，面积频谱效率)**：
$$\text{ASE} = \frac{\text{Throughput}}{\text{Area} \cdot \text{Bandwidth}} \quad [\text{bit/s/Hz/m}^2]$$
- 在给定条件下（femtocell 场景、随机信道接入、**带宽有限且固定**、**面积有限且固定**），吞吐量**存在上限**：小基站数从 X → 2X → 4X → 8X，吞吐量增长越来越慢，最终饱和。
- 原因：**小区间干扰 (inter-cell interference)**。

> 🔍 **为什么会饱和？** 在固定面积里，每加一个基站，你离服务基站更近了（信号 S ↑），但离干扰基站也更近了（干扰 I ↑）。当网络干扰受限（I ≫ N）时，S 和 I 按差不多的比例增长 → **SINR 基本不变**，加基站带来的收益越来越小。

**HetNet 中的干扰**：所有节点共用同一频段、同一无线接入技术（基于 OFDMA）；大量部署 LPN → **小区间干扰**，包括 **宏 → LPN 干扰** 和 **LPN → 宏干扰**。

**HetNet 的问题（三角关系）**
- 小区间干扰 → **性能下降**（小区边缘吞吐量、网络吞吐量）
- 海量节点 → **无线资源规划复杂** → 需要**自组织 (self-organization)**
- 需要协调 → **小区间信令开销**

## 5.4 HetNet 频谱分配

**固定分配（三种）**
| 方案 | 宏小区 | 微微小区 (Pico) | 特点 |
|---|---|---|---|
| **Reuse 1-1** | 每个宏小区都用全带宽 | 也用全带宽 | 频谱利用率最高，干扰最大 |
| **Reuse 3-1** | 三个宏小区各用 1/3 | 用全带宽 | 宏之间不干扰，但宏和 pico 仍然重叠 |
| **Orthogonal assignment 正交分配** | 宏用一部分频谱（内部再分三份） | 用**另一部分**，与宏不重叠 | **跨层（宏↔pico）无干扰**，但每层可用频谱变少 |

**Fixed vs Flexible reuse**
- **Fixed hard frequency reuse**：每个宏基站 (MBS) 固定占一段频率。
- **Flexible frequency reuse**：宏基站通过 **HII (High Interference Indicator，高干扰指示)** 反馈给微微基站 (PBS)，PBS 据此灵活选择使用哪些子频段 → 避开被宏基站重度使用的部分，同时尽量多用频谱。

## 5.5 传播模型很重要！

- **标准传播模型**：面积吞吐量随小区密度**线性增长**，能效也单调上升并饱和 → 显得"越密越好"。
- **LOS/NLOS 模型**（更真实，区分视距/非视距）：面积吞吐量增长慢得多（与标准模型有很大 **GAP**）；**能效先升后降，存在最优基站密度**。
- 结论：**标准系统模型会掩盖密集小区的问题**；**存在一个最优 BS 密度区间**。

> 🔍 **为什么 LOS/NLOS 模型下太密反而不好？** 基站很密时，不光服务基站是 LOS，很多**干扰基站也变成了 LOS**（没有被遮挡），干扰路径损耗指数变小 → 干扰增长比信号更快 → SINR 下降。再加上每个基站都要耗电 → 能效下降。

## 5.6 毫米波 (mmWave)

- 1G–4G 蜂窝用**微波** (300 MHz–3 GHz)；5G 可用**毫米波** (28 GHz、38–49 GHz、70–90 GHz… 到 300 GHz)。
- 蜂窝系统可用的微波频谱很少（美国最好情况下总共约 600 MHz）→ **频谱效率为王**（MIMO、MU-MIMO、HetNet）。
- mmWave 频谱**巨大**：可能有 29 GHz 可用（23 GHz、LMDS、38、40、46、47、49 GHz 和 E-band）；已用于 LAN、PAN、VANET；在蜂窝网中用于**回传 (backhaul)**。
- 缩写：E-band = 71–76 和 81–86 GHz；K-band = 18–27 GHz；Ka-band = 26.5–40 GHz；PAN = 个人局域网；VANET = 车载自组网；MU = 多用户。

**mmWave 频谱的影响**
- **共享授权接入**：降低成本，让运营商获得更多频谱
- **认知无线电**：与卫星、雷达共享频谱（机场的地面移动雷达用 K/Ka 频段）
- **传播模型不同**
- **天线尺寸小得多**（λ 小 → 天线小，一小块面板能放很多阵元）

**5G 新场景**：自主机器人（设备小）、自动驾驶（高速率）、V2X（低时延）、VR（高速率）→ 需要 mmWave 的高速率。

**阻挡 (Blockage) 是主要的信道损伤**：建筑物、行人、**手握**、**自身身体**遮挡 → 需要阻挡模型以及包含阻挡的系统分析。

**Massive MIMO @ mmWave**：基站 **256 根或更多天线**，手机也有大阵列 → 窄波束 → **小区外干扰更少**；需要把阻挡纳入考虑。**大阵列是 massive MIMO 的自然应用。**

**mmWave 要点**
- 观察：配置合适时覆盖可以接受；是提高单链路速率的有力候选；硬件可借鉴 60 GHz LAN/PAN 的经验；**高度定向天线可能从根本上改变系统设计**；**支持移动性是挑战**。
- 展望：随着 mmWave 频谱开放成为 5G 的一部分；与微波蜂窝系统**共存**；在回传等小众应用中仍会有用。

> 🔍 **为什么 mmWave 必须配大天线阵？**
> mmWave 路径损耗非常大 → 单天线覆盖极短。但 λ 很小（28 GHz 时 λ ≈ 1 cm），同样面积能塞下几百个阵元 → 用**波束成形**把能量集中成很窄的波束，天线增益补回路径损耗。
> 代价：波束窄 → 要对准用户（**波束管理**），用户移动/被挡时要迅速切换波束 → **移动性难支持**。

## 5.7 太赫兹 (THz)

- 频段 **0.1–10 THz**，位于 mmWave 和红外之间。
- 传统上叫 **"no man's land"**：对 RF 来说太高，对光来说太低。
- 正在走出纯理论研究：成像、安检、无损材料检测等商用应用已经出现。

| | Sub-6 GHz | mmWave | THz |
|---|---|---|---|
| 带宽 | 有限 | 大 (30–100 GHz) | 超大 (0.1–10 THz) |
| 覆盖 | 远 | 短 (≤200 m) | 超短 (≤20 m) |
| 速率 | 有限 | 高 (≤10 Gbps) | 超高 (≤100 Gbps) |
| 干扰抑制 | OFDM；OFDMA | 波束成形 | 极窄"笔形"波束成形 |
| 阻挡影响 | 小 | 中到高 | 高 |
| 可行架构 | Massive MIMO | Ultra mMIMO；**RIS**（可重构智能表面） | Cell-free massive MIMO；全息智能表面 |
| 局限 | 频谱稀缺、速率有限 | 易受阻挡 | 极易受阻挡 |
| 应用 | 低速率、容忍时延的业务 | 车联网、无人机、IoT、雷达 | XR、全息传送、IoE、非地面网络 |

**THz 应用场景**：XR 与全息传送；**工业 4.0 与数字孪生**（物理模型 ↔ 网络空间模型通过 THz 交换数据）；**CRAS**（Connected Robotics and Autonomous Systems，如通过 THz 下载 3D 地图）；**NTN**（Non-Terrestrial Networks：卫星、无人机、宏基站之间的 THz/mmWave 链路）。

**工业革命（背景知识）**：1.0 机械化（蒸汽机）→ 2.0 大规模生产（电、流水线）→ 3.0 自动化与数字化（计算机、互联网）→ 4.0 信息物理系统（IoT、大数据、云、早期 AI）→ 5.0 人机协作（生成式 AI、协作机器人、**6G**；强调可持续性和个性化）。

## 📝 课堂例题（Lecture 5）

**Q1：哪项描述超密集网络 (UDN)？** → **基站比用户多**。

**Q2：设计三种系统达到 6 bps/Hz 的频谱效率**（假设 $S = I + N$）
可用组件：SISO 和 MIMO（2×2 空间复用）；QPSK、16-QAM、64-QAM；编码率 3/4、1/2、1。

因为 $S = I+N$ → $\log_2(1 + 1) = 1$，所以
$$C = m \cdot B \cdot \log_2\left[1+\frac{S}{I+N}\right] = m\cdot B \;\Rightarrow\; C/B = m$$
$m$ = 空间流数 × 每符号比特数 × 编码率。

| 方案 | 计算 | 结果 |
|---|---|---|
| SISO + 64-QAM + $R_c = 1$ | 1 × 6 × 1 | 6 bps/Hz ✔ |
| MIMO + 16-QAM + $R_c = 3/4$ | 2 × 4 × 3/4 | 6 bps/Hz ✔ |
| MIMO + 64-QAM + $R_c = 1/2$ | 2 × 6 × 1/2 | 6 bps/Hz ✔ |

> 💡 做题套路：列出 {1, 2} × {2, 4, 6} × {3/4, 1/2, 1} 的所有组合，挑出乘积 = 6 的。穷举后恰好只有上面三种（例如 MIMO + QPSK 最多 2×2×1 = 4，SISO + 16QAM 最多 4，都不够）。

**Q3：MIMO 信道矩阵的秩 (rank)**
- 秩 = 独立列的个数。
- **秩高 → 用空间复用**（高速率）；**秩低 → 用空间分集**（高可靠性）。

$$H_1 = \begin{bmatrix}1&1&-1\\2&1&0\\3&0&0\end{bmatrix},\quad H_2 = \begin{bmatrix}0.5&-1&1\\1&-2&2\\1.5&-3&3\end{bmatrix}$$

- $H_1$：三列相互独立 → **rank = 3** → 适合**高速率**。（验证：$\det H_1 = 3 \cdot (1\cdot0-(-1)\cdot1) = 3 \neq 0$ → 满秩。）
- $H_2$：第 2、3 列分别是第 1 列 × (−2) 和 × 2 → **rank = 1** → 适合**高可靠性**。

> 🔍 **为什么秩决定能开多少个流？** 秩 = 信道里"独立的空间通道"数。rank = 3 → 最多同时发 3 路互不混淆的数据流。rank = 1 → 所有天线"看到"的信道本质上是同一个方向（高度相关），发多路数据接收端也分不开，不如把所有天线用来发同一份数据，提高可靠性。

**Q4：CDMA 码选择与解码** ⭐（13 + 12 分，考试原题风格）
设定：比特 0 → 正脉冲 +L，比特 1 → 负脉冲 −L。站 A 的码是 101111；站 B 可以从 101110、010101、000101 中选。

**(a) B 应该选哪个码？** —— 选与 A **正交**（点积 = 0）的码，CDMA 靠码正交在码域区分用户。
映射（码中 1 → −1，0 → +1）：
- A：101111 → (−1, +1, −1, −1, −1, −1)
- 101110 → (−1, +1, −1, −1, −1, +1)：点积 = 1+1+1+1+1−1 = **4** ≠ 0
- 010101 → (+1, −1, +1, −1, +1, −1)：点积 = −1−1−1+1−1+1 = **−2** ≠ 0
- 000101 → (+1, +1, +1, −1, +1, −1)：点积 = −1+1−1+1−1+1 = **0** ✔

→ **B 应选 000101**。

**(b) A 发 1、B 发 0，接收端解出什么？**
- A 发送：−L × (−1, +1, −1, −1, −1, −1) = (+L, −L, +L, +L, +L, +L)
- B 发送：+L × (+1, +1, +1, −1, +1, −1) = (+L, +L, +L, −L, +L, −L)
- 接收端收到叠加信号：**(+2L, 0, +2L, 0, +2L, 0)**
- 解 A：与 A 的码做点积 = −2L + 0 − 2L + 0 − 2L + 0 = **−6L < 0 → 比特 1** ✔
- 解 B：与 B 的码做点积 = +2L + 0 + 2L + 0 + 2L + 0 = **+6L > 0 → 比特 0** ✔

> 🔍 **为什么能分开？** 对 A 的码做点积时，B 的贡献 = B 的比特 × ⟨B 码, A 码⟩ = B 的比特 × 0 = 0，**B 被完全消掉**，只剩 A 自己的 $\pm 6L$（6 = 码长）。这就是"正交"的意义。如果选了不正交的码（如 101110），B 的信号会"泄漏"进 A 的判决，可能导致误判。
> ⚠️ 注意映射方向：本题**比特 1 → −1，0 → +1**，别弄反。判决：点积 > 0 → 0，< 0 → 1。

## 自测题

<details>
<summary>12. 为什么小基站不能无限加下去？</summary>

在固定面积和固定带宽下，干扰随密度同步增加，SINR 不再提升 → 面积频谱效率饱和；在 LOS/NLOS 模型下，干扰基站也变成 LOS，性能和能效甚至会下降 → 存在最优密度。
</details>

<details>
<summary>13. 用 2×2 MIMO、QPSK 和编码率 3/4，频谱效率是多少？</summary>

2 × 2 × 3/4 = **3 bps/Hz**（假设 S = I + N）。
</details>

<details>
<summary>14. CDMA：A 码 = 1100，B 应该在 1010 和 1110 中选哪个？</summary>

映射 1 → −1，0 → +1：A = (−1, −1, +1, +1)。
1010 → (−1, +1, −1, +1)：点积 = 1 − 1 − 1 + 1 = 0 ✔
1110 → (−1, −1, −1, +1)：点积 = 1 + 1 − 1 + 1 = 2 ✘
→ 选 **1010**。
</details>

<details>
<summary>15. mmWave 最主要的信道损伤是什么？用什么技术补偿路径损耗？</summary>

阻挡 (blockage)：建筑、行人、手、身体。用大规模天线阵列 + 波束成形（massive MIMO）获得高增益。
</details>
