1. 互联网 = **网络的网络 (network of networks)**:接入网 (access net) → 区域网 (regional net) → ISP;ISP 之间通过 **IXP(互联网交换点)** 互连。
2. 中心是少量连接良好的大网:**Tier-1 商业 ISP**(如 Level 3、Sprint、AT&T、NTT,覆盖全国/国际)和**内容提供商网络 (content provider network)**(如 Google:连接自己数据中心的私有网络,常**绕过** Tier-1 和区域 ISP)。
3. 电信网是在**旧技术上逐步升级**建起来的;早期用**铜线**,距离限制在**几公里**。
4. 各种介质对比(课件表):**光纤带宽 180–370 THz、损耗 0.2–0.5 dB/km、中继间隔 40 km**;铜线/同轴损耗大得多、中继间隔只有 **2 km / 1–9 km**。**光纤延迟 5 µs/km,并不比铜线快**。
5. 光纤容量远超 coax / 卫星 / 4G,且随距离衰减最小。
6. 网络层次:**接入 (access,离用户最近) → 汇聚 (aggregation) → 城域 (metro,城市环网) → 核心 (inner/outer core)**;光通信在各层都用,尤其是汇聚以上。

### 2. 互联网的演进与结构

**早期演进 (Internet early evolution)**
- 1969 ARPANET 开始 → 1970 发展 → 1973 走向国际 → 1982 社区增长 → 1990 ARPANET 退役并入互联网 → 1992 NSFNET T3 → 1993 真正全球化。

**网络的网络 (network of networks)**
- 很多**接入网 (access net)** 连到 ISP A / B / C。
- ISP 之间通过 **IXP (Internet Exchange Point,互联网交换点)** 互连。
- 也可能出现**区域网 (regional net)**,把接入网连到 ISP。

**层级结构**
- 顶层:**Tier-1 ISP** 和 **Google**(内容提供商)
- 中间:**区域 ISP (Regional ISP)**,通过 IXP 互连
- 底层:**接入 ISP (access ISP)**

- 中心是**少量连接良好的大网络**:
  - **Tier-1 商业 ISP**(Level 3、Sprint、AT&T、NTT):全国和国际覆盖
  - **内容提供商网络**(如 Google):连接自己数据中心和互联网的**私有网络**,经常**绕过 Tier-1 和区域 ISP**

> 🔍 从零理解 IXP:
> 1. 两个 ISP 想互相交换流量,可以各自拉线到对方,但如果有 10 个 ISP,两两连线要 45 条。
> 2. IXP 是一个公共的"交换机房",大家各拉一条线到 IXP,在里面互连 → 10 条线就够。
> 3. 例子(课件没讲,了解即可):都柏林的 INEX 就是爱尔兰的 IXP。

### 3. 传输距离:从铜线到光纤

- 电信网是**在旧技术上逐步升级**建起来的。
- 最初用**铜线 (copper)**,传输距离限制在**几公里**。
- 课件图(Attenuation of guided media):**双绞线**衰减随频率上升很快,**同轴**好一些,**光纤**在很高频率(~THz)衰减仍然很低。
  - **最后一公里 (last mile)**:用户到第一个节点,传统是双绞线。
  - **汇聚 (aggregation)**:往上汇聚流量。

**光通信来了 (Then optical communication came along)**
- 课件柱状图(容量 Gb/s):**光纤 ≈ 5000**,coax ≈ 10,卫星 ≈ 2,4G ≈ 0.1。
- 课件折线图(衰减 dB vs 距离 km,1–20 km):**coax** 和**卫星**衰减随距离上升很多,**4G** 居中,**光纤最低**、几乎平的。

> 🔍 从零理解"为什么铜线只能走几公里":
> 1. 铜线里传数据 = 变化的电流 → 会辐射能量、受干扰(第 2 章)。
> 2. 频率越高衰减越大 → 想要高速率就得用高频 → 距离越长信号越弱。
> 3. 香农 C = B·log₂(1+S/N):距离长 → S/N 低、可用带宽 B 小 → 容量低。
> 4. 光纤 0.2 dB/km:20 km 才 4 dB(功率剩约 40%),所以光纤能走远而且带宽巨大。

### 4. 衰减对比表 (Attenuation comparison)

| 介质 | 频率范围 | 典型衰减 | 典型延迟 | 中继间隔 (repeater spacing) |
|---|---|---|---|---|
| 双绞线(加感 with loading) | 0–3.5 kHz | 0.2 dB/km @1 kHz | 50 µs/km | 2 km |
| 双绞线(多对电缆) | 0–1 MHz | 3 dB/km @1 kHz | 5 µs/km | 2 km |
| 同轴电缆 (coax) | 0–500 MHz | 7 dB/km @10 MHz | 4 µs/km | 1–9 km |
| **光纤 (optical fibre)** | **180–370 THz** | **0.2–0.5 dB/km** | **5 µs/km** | **40 km** |

> 🔍 从零理解"延迟 5 µs/km":
> 1. 先算光在光纤里跑多快:
>    - c₀ = 真空中的光速 = 3×10⁸ m/s(每秒 30 万 km)。
>    - n = 折射率 (refractive index),表示材料让光慢了多少倍。光纤(玻璃)n ≈ 1.5。
>    - 光纤里的光速 c = c₀ / n = 3×10⁸ / 1.5 = **2×10⁸ m/s**,也就是每秒 **20 万 km**(比真空慢三分之一)。
> 2. 走 1 km 需要 1 / 200 000 s = 5 × 10⁻⁶ s = **5 µs**。
> 3. 同轴 4 µs/km 甚至更快 → 光纤**不是因为更快**才好,而是因为**带宽大、损耗低、信噪比高**。

> 📝 考试怎么考:
> - 2022/23 Q14(MCQ):下面哪个**不是**光纤宽带比铜线好的原因?→ **a) 光在光纤中的速度比电流在铜线中快**(看表:延迟差不多,这不是原因)。其他三个(带宽更高、信噪比更高、损耗更低)都是原因。
> - 接入网大题(2020/21 Q4a、2021/22 Q4a、2023/24 Q4b):用**香农公式**解释为什么从全铜 → 铜光混合 → 光纤到户(FTTH);这一章提供背景:铜线损耗高、距离短、带宽小。

> ⚠ 常见错误:以为光纤"更快"是指传播速度更快。实际是**容量(带宽)更大**,传播延迟差不多。

### 5. 光通信在网络中的使用位置

从用户往里:
1. **接入层 (Access)**:离用户最近,比如小区里的设备;"最后一公里 (last mile)"。
2. **汇聚层 (Aggregation)**:把多个接入点的流量汇聚起来。
3. **城域网 (Metro)**:城市范围内的环网 (ring)。
4. **核心网 (Inner Core / Outer Core)**:最中心、连接最密集,承载全国甚至全球流量。

- 越往核心,流量越大、距离越长 → 越需要光纤;第 3 章的**相干系统**就是先用在核心和城域网,以后才进接入网。

## 自测题

1. 互联网"网络的网络"结构里,IXP 的作用是什么?
<details><summary>答案</summary>让多个 ISP / 网络在一个公共点互连交换流量。</details>

2. 内容提供商网络(如 Google)和 Tier-1 ISP 有什么不同?
<details><summary>答案</summary>它是连接自己数据中心和互联网的私有网络,经常绕过 Tier-1 和区域 ISP;Tier-1 是有全国/国际覆盖的商业 ISP。</details>

3. 光纤和同轴电缆的衰减、中继间隔分别是多少?
<details><summary>答案</summary>光纤 0.2–0.5 dB/km,中继 40 km;同轴 7 dB/km @10 MHz,中继 1–9 km。</details>

4. "光纤比铜线好是因为光在光纤中更快"——对不对?为什么?
<details><summary>答案</summary>不对。光纤延迟约 5 µs/km,和铜线差不多(同轴 4 µs/km)。光纤好在带宽大、损耗低、信噪比高。</details>

5. 按从用户到中心的顺序写出网络的四个层次。
<details><summary>答案</summary>接入 (access) → 汇聚 (aggregation) → 城域 (metro) → 核心 (core)。</details>
